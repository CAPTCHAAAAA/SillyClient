# Maple Mono

`MapleMono-Variable.woff2` is the unmodified upright variable WOFF2 from
`subframe7536/maple-font`, commit `5ee93150fbafe59dc805c2f64ad879fd14c3ce78`.

- Source: https://github.com/subframe7536/maple-font
- Upstream file: `woff2/var/MapleMono[wght]-VF.woff2`
- License: SIL Open Font License 1.1; see `MapleMono-OFL.txt`.
- SHA-256: `e7080ef37fa8b3a38f71446e53e546634c27ce2cfe97673478cafc029d6344ee`
- Size: 130,908 bytes.

The bundled font is limited to terminal output and command input. Its weight
axis covers 100–800. Chinese text falls back to the platform's UI font, and
programming ligatures are disabled to preserve literal command characters.
