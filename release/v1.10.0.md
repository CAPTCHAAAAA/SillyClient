# SillyClient v1.10.0

> Windows：修复 Git 启动失败，并支持自定义实例存储根。Android：锁定设备最高刷新率，酒馆在前台时让控制台休眠。iOS：本版开始提供未签名 IPA，iOS 14.0 及以上。引导、密码、迁移和界面为 Windows / Android 共用。

## 变更内容

**界面与功能**（Windows / Android）

- 新手引导改为 7 步、14 个子视图：新建实例、实例卡片、密码保护、数据迁移、控制台、背景与主题、APP 设置。配图用的是当前界面。可从 APP 设置重新查看。
- 可为实例设置访问密码。解锁在本地完成，密码不进 URL，也不进日志，断网可用。Windows 同步了完整交互。
- 复制迁移把旧酒馆数据复制到独立目录，原文件不动。原地接管直接使用旧目录，在客户端移除实例只解除登记，不删除原目录。迁移默认排除 `secrets.json`。
- 备份 JSON 改为原生读取。Android 走系统选择器，Windows 走原生对话框。
- ZIP 导入支持多类型识别、后台解压、单根目录压平和运行底座补齐。修复 Windows 导入时的 EPERM 冲突。
- 「预制安装」改名为「预设安装」。创建时可选择内置主题和壁纸，例如 SC Bordeaux。失败自动回滚。
- 实例卡片的停止态和运行态拆开，同一位置过渡。双击标题可重命名。
- 轮播翻页和指示器按视口中心对齐。指示器可点、可滑，也可用键盘左右键。
- 控制台拆成实例管理、创建实例、APP 设置、壁纸、新手引导和确认框。启动面板可在控制台和后台酒馆之间切换。
- 桌面 Esc 和手机返回键走同一层浮层栈，避免弹窗穿透和遮罩残留。
- 更新后第一次启动会打开更新说明。之后可在「APP 设置 → 维护」再打开。
- 设置抽屉和实例管理弹窗使用同一套进入和退出动效。

**Windows**

- 修复 Git 环境变量大小写导致的 `spawn git ENOENT`。自动查找常见 Git 安装路径。
- 支持自定义默认实例存储根，把安装包更新和实例数据分开。
- 存储路径可以无损改位置，也可以重命名底层文件夹。管理面板补上重命名、删除和绝对路径。
- 优化启动速度和实例卡片渲染。

**Android**

- 锁定设备支持的最高刷新率，包括 120Hz 和 90Hz。
- 去掉移动端多层动态背景模糊和卡片实时噪点。
- 滚动交给硬件合成，轮播使用惯性滚动。
- 酒馆在前台时，底下的控制台休眠。
- 顶部取色改为事件驱动，停止滑动后不再截屏。进入酒馆时先用缓存色。

**iOS**

- 新增 iOS 支持。iOS 14.0 及以上，提供未签名 IPA，可用自签名或常见侧载方式安装。
- 内置进程内 Node 运行时，可离线运行酒馆。
- 适配状态栏、底部安全区和麦克风输入。
- 可用系统文档选择器关联实例目录。已在运行的实例不会被重复启动。
