# SillyClient 1.10.0

> 本版汇总自 1.9.1 以来的全部用户可见更新。

## 核心变化

### 1. 新手引导全面扩充（7 大步骤）
- 新手引导升级为 7 大步骤、共 14 个完整子视图：新建实例、实例卡片、密码保护、数据迁移、控制台、背景与主题、APP 设置，全部采用当前界面的实际配图。
- 新增「密码保护」与「数据迁移」两大核心引导步骤，并补充实例卡片私密锁定的界面演示。
- 步骤切换与内容过渡更连贯，可从 APP 设置随时重新查看。

### 2. 实例访问密码保护（本地保险开关）
- 支持为实例设置访问密码，实例卡片呈现锁定的私密状态标记。
- 解锁完全在本地完成，密码不离开设备、不进入 URL 与日志，断网同样可用。
- Windows 端同步实现密码保护的完整交互链路。

### 3. 数据迁移与文件导入
- 复制迁移：将旧版 SillyTavern 数据复制迁移至独立目录运行，新旧隔离，原文件不受影响，支持自定义目标路径。
- 原地接管：直接接管旧版酒馆所在目录运行，不产生重复副本；在客户端移除实例时仅解除登记，不删除原目录中的物理文件。
- 迁移默认排除 `secrets.json` 防止历史密钥泄露，可按需开启随同导入。
- 新增跨端原生文本读取接口 `TarvenEnv.readTextFile`（Android SAF / Windows 原生对话框），解决备份 JSON 导入在部分 WebView 中点击无响应的问题。
- 增强 ZIP 导入兼容性：多类型 ZIP 识别、后台异步解压、单根包裹压平、基础运行底座自动补齐；修复 Windows ZIP 导入 EPERM 冲突。

### 4. 预设安装（原「预制安装」）
- 「预制安装」统一更名为「预设安装」。
- 创建实例时可选择内置伴生主题与配套壁纸预设（如 SC Bordeaux），安装完成后自动应用，失败自动回滚。

### 5. 实例卡片与轮播架构重构（高内聚低耦合）
- 实例卡片停止态与运行态彻底解耦为 `InstanceStoppedCard` / `RunningConsoleCard`，同位驻留平滑溶变，消除 hover 抖动与展开失效。
- 支持双击实例标题就地重命名，Enter 保存、Esc 取消。
- 轮播翻页键与指示器重构为基于视口物理中心的真实像素对齐，消除反跳与抢占抽搐。
- 轮播指示器升级为无边框 Apple 流体弹簧胶囊，支持触控滑动、小圆点直选与键盘左右键导航。

### 6. 控制台解耦、弹窗与向导治理
- 将原本庞大的单体控制台拆分为实例管理、创建实例、APP 设置、壁纸定制、新手引导与确认交互等高内聚独立模态组件。
- 启动控制台新增最小化后台活动胶囊（Activity Capsule），支持在控制面板与后台运行中的酒馆间无感切换。
- 引入统一全局浮层栈治理（`useLayerStack`），适配桌面 ESC 与移动端物理返回键，杜绝弹窗穿透与遮罩残留。
- 建立语义化分层 Z-Index 标尺；消除输入框 focus 的荧光绿与外发光阴影；向导与背景弹窗昼夜平滑高度跟随溶变。
- 迁移向导的敏感凭据说明、运行机制与预检结果统一改为红色感叹号按需展开（`InfoBadgeButton` + 平滑手风琴），默认保持极简表单。

### 7. 更新公告画布（What's New）
- 更新后首次启动自动呈现全屏虚化柔焦沉浸画布（毛玻璃遮罩彻底虚化底座主界面）。
- 可在「APP 设置 - 维护」中随时重新打开查看。
- 采用轻拟物扁平无边框设计，更新说明按「新功能 / 新更新 / 新优化」三维精简呈现。
- 设置抽屉（通用/数据/维护）与实例管理弹窗（启动/快照/存储/终端/关于）全域接入同位驻留 DOM、微位移升降与高斯模糊交叉溶变动效。

### 8. Android 性能与高刷重构
- 申请并锁定设备支持的最高屏幕刷新率（120Hz / 90Hz），解除 60Hz 帧率墙限制。
- 移除移动端 14 层动态 `backdrop-filter` 与卡片 SVG 实时噪点着色器，大幅降低 GPU 显存带宽与离屏渲染开销。
- 移除滑动监听中的强制同步重排（Forced Synchronous Layout），滚动交由硬件合成器处理；轮播开启硬件惯性滚动与横向手势直通。
- 酒馆处于前台时底座控制台 WebView 深度休眠，消除双 WebView 资源争抢。
- 顶部变色龙改为纯事件驱动的轻量 DOM 探针取色，停止滑动期间的截屏挂起；进入酒馆首帧直接应用缓存色消除色差过渡。
- 实例卡片与背景提升为独立合成层并加入排版隔离，消除长列表 LayoutShift。

### 9. Windows 端强化
- 修复 Windows Git 环境变量大小写敏感导致的 `spawn git ENOENT` 异常，自动探测并补齐常见 Git 安装路径与基础工具；
- 对齐移动端支持自定义默认实例存储根目录，有效隔离安装包更新与实例数据；
- 实例存储路径无损重定位与底层文件夹重命名同步，实例管理面板补齐重命名/删除操作行与绝对路径展示；
- 强化运行时与数据迁移引擎，修复 ZIP 导入 EPERM 冲突；迁移向导设计重构并在更新后开屏呈现；
- 优化启动速度与实例卡片渲染（memoization），恢复轮播顺滑手感。

### 10. iOS 平台支持
- 新增 iOS 平台官方支持：支持 iOS 14.0+，提供免越狱标准 IPA（兼容万能签、爱思助手、AltStore、TrollStore、SideStore 或自签名证书安装）。
- 内置 NodeMobile 进程内运行时与 SillyTavern 纯 JS 生产服务，支持完全离线运行。
- 原生深度适配：变色龙双引擎顶部取色熔接、灵动岛与状态栏硬件避让、底部满版通底（Full Bleed）与 Home Indicator 智能避让；支持麦克风录音与语音输入（STT / WebRTC）。
- 沙盒与目录管理：支持系统文档选择器直接选择并关联实例目录；已运行实例支持无感切回与重复启动保护。

- Windows：Windows 10 / 11（x64）。
- iOS：iOS 14.0 及以上，arm64 设备。
