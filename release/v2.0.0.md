# SillyClient 2.0.0

## 1. 数据迁移与文件导入

- **旧版酒馆数据迁移**：
  - **复制迁移**：支持将旧版 SillyTavern 的全部数据（聊天记录、角色、预设、世界书、扩展插件）完整复制到新的独立存储目录下运行。新旧数据相互独立，原文件保持原样不受任何改动；支持自由指定目标保存路径或恢复默认。
  - **原地接管**：直接关联旧版酒馆所在目录运行，不产生重复文件副本，节省磁盘空间；在客户端中移除实例时仅解除登记关联，绝不会删除原目录中的任何物理文件。
  - **私有凭据控制**：迁移时默认排除 `secrets.json`，防止历史密钥泄露；可按需自主开启随同导入。
- **系统原生文件导入支持**：
  - 新增跨端原生文本读取接口 `TarvenEnv.readTextFile`，Android 端接入系统 SAF 存储框架，Windows 端接入系统原生文件选择对话框，解决设置抽屉中导入备份 JSON 在部分 WebView 中点击无响应的问题。
  - 增强 ZIP 压缩包导入兼容性，扩展多种 ZIP MIME 类型并转入后台异步解压，支持单根包裹自动识别压平；若解压后缺失运行时底座会自动补齐基础运行环境。

## 2. Android 端性能与高刷重构

- **减轻移动端 GPU 与渲染负担**：
  - 移除了移动端挂载的 14 层动态 `backdrop-filter` 渐进遮罩与卡片上的 SVG 实时噪点着色器滤镜，大幅降低 GPU 显存带宽与离屏渲染开销。
  - 移除了滑动监听中的强制同步重排（Forced Synchronous Layout），滚动计算交由硬件合成器直接处理。
- **高刷锁定与硬件加速**：
  - Android 12 及以上版本在 WebView 底层句柄注入 `setFrameRate` 锁定 120Hz 硬件刷新率，解决手势释放后系统动态降频到 60Hz 的掉帧问题。
  - Launcher WebView 开启 `LAYER_TYPE_HARDWARE` 硬件加速并设置 `OVER_SCROLL_NEVER` 消除回弹拷贝。
  - 实例轮播容器开启 `-webkit-overflow-scrolling: touch` 硬件惯性滚动与 `touch-action: pan-x`，实例卡片与背景提升为独立合成层并加入排版隔离。
- **变色龙取色与生命周期调度**：
  - 顶部变色龙改为纯事件驱动的轻量 DOM 探针计算，停止滑动期间的截屏挂起（PixelCopy）；进入酒馆首帧直接应用缓存色，消除初期的色差过渡。
  - 酒馆前台运行时，底座控制台 WebView 自动深度休眠，避免双 WebView 抢占 CPU/GPU 资源。

## 3. 前端界面与动效

- **信息折叠交互**：
  - 向导接入方式、私有凭据说明与数据检测结果统一改为红色感叹号展开模式（`InfoBadgeButton` + `motion-accordion`），默认保持极简表单，点击后平滑展开详细说明，再次点击折叠收起。
- **指示器与卡片过渡**：
  - 移除轮播指示器外层边框，改为小圆点配合物理弹簧滑块，支持触控滑动、小圆点直选与键盘左右键导航。
  - 实例卡片停止态与运行态彻底解耦为同位驻留，状态切换时平滑淡入淡出，消除 hover 抖动与位置抢占；运行中卡片直接作为控制台查看日志并支持实时命令输入。
  - 向导子模式（复制迁移 / 原地接管）切换引入同位驻留 DOM 与平滑高度自适应变形。
