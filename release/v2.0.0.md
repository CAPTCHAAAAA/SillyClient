# SillyClient 2.0.0

## 核心变化

SillyClient 2.0.0 是一次里程碑式的重磅版本升级。本次更新聚焦于 Android 端极致性能与高刷重构、全新控制台 UI 美学与交互升级，并正式实装了实用的跨平台“数据迁移”与原生文件导入系统。

---

### 1. Android 端性能全链路极致重构（对齐桌面级 120Hz 丝滑体验）

- **彻底拔除移动端三大 GPU/CPU 性能深坑**：
  - **移除 14 层动态毛玻璃模糊**：排查并彻底拔除了在移动端注入的 14 层带有 `mask-image` 边缘渐进遮罩的 `backdrop-filter` 层，消除了 Adreno / Mali GPU 每帧多达十数次的昂贵离屏模糊与遮罩合成，显存带宽占用骤降。
  - **拔除卡片实时 SVG 噪点计算**：移除了卡片上挂载的 SVG `feTurbulence` 实时着色器噪点与 `mix-blend-mode: overlay`，消除移动 GPU 的着色管线重绘压力。
  - **杜绝滚动监听的强制同步重排（Forced Synchronous Layout）**：彻底解绑移动端滚动时的高频全屏重排计算，杜绝丢帧卡顿。
- **全链路硬件加速与排版隔离**：
  - 实例轮播容器全面引入 `-webkit-overflow-scrolling: touch` 惯性飞轮与 `touch-action: pan-x` 零 JS 阻塞手势，手势滑动直接交由 Chromium 合成器线程调度。
  - 实例卡片提升为独立硬件合成层，引入 `contain: layout paint` 隔离排版；背景 Screensaver 全面升级为 GPU 纯变换 `translate3d`。
- **Android 宿主 120Hz 锁帧与底层优化**：
  - Launcher WebView 开启 `LAYER_TYPE_HARDWARE` 硬件加速并设置 `OVER_SCROLL_NEVER` 消除回弹拷贝。
  - 在 Android 12+ 上直接通过反射在 WebView 句柄注入 `setFrameRate` 锁定 120Hz 硬件刷新率，彻底消除手势松手后系统 LTPO 动态掉帧。
- **变色龙双引擎与双 WebView 生命周期治理**：
  - ChameleonEngine 升级为零轮询纯事件驱动机制，优先通过轻量 DOM 探针计算取色，彻底消灭滑动期间同步截屏（PixelCopy）导致的 GPU pipeline stall。
  - 进入酒馆首帧即时应用缓存色，实现 0ms 色差无缝对齐；酒馆前台运行时底座 WebView 自动深度休眠，彻底释放 CPU/GPU 资源。

### 2. 前端 UI/UX 全新更改与视觉美学升级

- **全面恢复经典小红点感叹号展开模式（InfoBadgeButton + motion-accordion）**：
  - 彻底拔除直接平铺大段机制说明的生硬样式，全面恢复精致醒目的红色感叹号（`!`）交互；
  - 接入方式、私有凭据（`secrets.json`）与数据预检详情全链路统一折叠，常态下界面回归极简、克制的高级表单质感，需要时点击丝滑展开纯客观机制说明。
- **无边框 Apple 流体果冻弹簧指示器**：
  - 拔除外包胶囊边框，指示器由舒适热区（22px）纯净圆点与 Apple 流体弹簧过冲滑块构成；
  - 支持圆点直选、键盘左右键与触摸滚动全模态支持，滑动过程带有动态流体延展与物理平滑回弹。
- **卡片架构解耦与同位驻留优雅过渡**：
  - 彻底解耦实例停止态与运行态卡片，卡片切换采用同位驻留 DOM 与 `cubic-bezier(0.22, 1, 0.36, 1)` 昼夜级优雅溶变，杜绝 hover 抖动与吸附抽搐；
  - 运行中卡片展开为轻拟物实色控制台，支持原生命令交互与实时日志流。
- **向导子模式三态级动效**：
  - “复制迁移”与“原地接管”之间落地同位驻留 DOM、微位移升降与高斯虚化溶变，容器高度由 `ResizeObserver` 结合物理缓动曲线平滑自适应，动效质感与主三态完全对齐。

### 3. 重磅新增跨平台“数据迁移”与实用导入能力

- **数据迁移（Data Migration）**：
  - **复制迁移（安全独立沙盒）**：支持将已有 SillyTavern 完整数据（聊天记录、角色、预设、世界书、扩展插件等）完整复制迁入独立受管存储目录，与原酒馆隔离运行；支持自由指定目标保存路径或一键恢复默认。原文件不作任何改动，去留由用户自行决定。
  - **原地接管（零额外存储）**：直接以现有本地旧酒馆目录作为运行基准，无需额外拷贝占用存储；特别加入**卸载防删保护机制**——若在客户端中移除实例仅注销登记记录，**绝不误删用户原物理文件**。
  - **私有凭据自主脱敏**：默认脱敏排除 `secrets.json`，用户可自主开启随同迁移 API Key 与认证信息。
- **原生文件读取与系统级兼容**：
  - 新增跨端原生 `TarvenEnv.readTextFile` 接口（Android 基于 SAF `ACTION_OPEN_DOCUMENT`，Windows 基于 Electron 原生 Dialog），彻底修复实例备份 JSON 导入无响应缺陷。
  - Android 深度支持 SAF 目录树（`content://.../tree/...`）递归安全提取；优化 `pickZipFile` MIME 类型兼容，支持大文件后台异步解压拷贝与单根包裹自动压平，缺失运行时底座时自动匹配挂载基础环境。
