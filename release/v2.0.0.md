# SillyClient v2.0.0

> Windows：备份 JSON 改为原生对话框读取，并支持复制迁移与原地接管。Android：锁定高刷新率，去掉多层动态模糊，酒馆在前台时让控制台休眠。iOS：本版没有安装包。迁移和导入为 Windows / Android 共用。

## 变更内容

**迁移与导入**（Windows / Android）

- 复制迁移把旧酒馆数据复制到独立目录。聊天记录、角色、预设、世界书和扩展会一起复制。原文件不动。
- 原地接管直接使用旧目录，不复制一份。在客户端移除实例只解除登记，不删除原目录。
- 迁移默认排除 `secrets.json`。可以按需改为一起导入。
- 备份 JSON 改为原生读取。Android 走系统选择器，Windows 走原生对话框。
- ZIP 导入支持更多类型、后台解压、单根目录压平。解压后如果缺运行底座，会补上基础运行环境。

**界面**（Windows / Android）

- 接入方式、私有凭据和预检结果默认收起，点开后再展开说明。
- 轮播指示器改为圆点加滑块，可点、可滑，也可用键盘左右键。
- 实例卡片的停止态和运行态拆开，同一位置过渡。运行中的卡片可以直接看日志、输入命令。
- 复制迁移和原地接管切换时，向导高度跟着内容变。

**Windows**

- 备份 JSON 使用系统文件对话框。

**Android**

- 去掉移动端多层动态背景模糊和卡片实时噪点。
- 滚动交给硬件合成，不再在滑动监听里强制同步排版。
- Android 12 及以上锁定 120Hz。轮播使用惯性滚动。
- 顶部取色改为事件驱动，停止滑动后不再截屏。进入酒馆时先用缓存色。
- 酒馆在前台时，底下的控制台休眠。

**iOS**

- 本版没有安装包。
