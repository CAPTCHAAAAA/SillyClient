# SillyClient v1.3.0

> Windows：内置 Node.js v22.16.0，酒馆改为独立窗口。Android：同步更换应用图标，并修复安全区轮询导致的点击失效。iOS：本版没有安装包。

## 变更内容

**界面**（Windows / Android）

- 全面替换应用图标（聊天气泡设计）。
- 修复 flattenExtractedDir 逻辑导致 package.json 找不到。

**Windows**

- 内置 Node.js v22.16.0，不依赖系统安装。
- 酒馆改为独立 BrowserWindow 窗口。
- 修复 npm install 报 ENOENT（npm-cli.js 由内置 node.exe 执行）。
- 修复端口被 Hyper-V 保留导致启动失败。

**Android**

- 修复 getSafeInsets 无限轮询导致点击失效。

**iOS**

- 本版没有安装包。

## 下载与校验

- Windows：`SillyClient-Setup-1.3.0.exe`（348 MB）。
- Android：`SillyClient-1.3.0-android.apk`（72 MB）。
- iOS：本版没有安装包。
