# SillyClient v1.4.1

> Windows：修复 node.exe 被打进 asar 后无法启动 npm。Android：没有新安装包，继续使用 v1.4.0。iOS：本版没有安装包。

## 变更内容

**Windows**

- 修复 `npm install` 报 `spawn node.exe ENOENT`。原因是 `node.exe` 被打进 `app.asar`，无法执行归档里的二进制文件。
- 改为用 extraResources 把 `runtime/node` 复制到 `resources/runtime/node`，不经过 asar。安装后 `node.exe` 位于该目录，`npm-cli.js` 位于其下的 npm bin。
- `paths.ts` 改为用 `process.resourcesPath` 定位 extraResources。
- 修复 electron-builder 输出目录与 TypeScript 编译目录都叫 `dist`，导致递归打包，app.asar 达到 106 GB。输出目录改为 `release/`。

**Android**

- 本版没有新改动，也没有新安装包。继续使用 v1.4.0 的安装包。

**iOS**

- 本版没有安装包。

## 下载与校验

- Windows：`SillyClient-Setup-1.4.1.exe`（104 MB）。
- Android：本版没有新安装包。
- iOS：本版没有安装包。
