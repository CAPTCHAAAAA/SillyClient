# SillyClient v1.14.5

> iOS 紧急修复版（`1.14.5` / Build `50`）：针对真机复现的「进入文件夹点『打开』后弹窗收起但输入框仍为空、粘贴『我的 iPhone ▸ ...』显示名称后报错英文路径错误」问题，移除覆盖系统文件选择器内部代理的 `presentationController?.delegate` 与 `.formSheet` 强制设置并加装异常分离兜底提示，同时在创建与迁移前端入口前置拦截非本地路径输入并补齐中文提示。本版仅更新 iOS，继续跳过 Windows 与 Android（继续使用 [`v1.14.1`](https://github.com/CAPTCHAAAAA/SillyClient/releases/tag/v1.14.1)，后续统一整合）。

## iOS 修复

- **修复文件选择器点「打开」后静默丢弃结果的问题**：
  - `TarvenEnvPlugin.swift` 移除 `UIAdaptivePresentationControllerDelegate`、`picker.presentationController?.delegate = self` 与 `picker.modalPresentationStyle = .formSheet` 覆盖，保留 `.automatic` 默认呈现，不再干扰 UIKit / 远程「文件」选择器的内部代理与回调；
  - 新增主队列分离检测定时器（`startPickerDismissMonitor(for:call:)`，分离确认窗口 `>= 0.5s`）：若选择器未收到选中或取消回调便异常关闭，明确返回 `PICKER_DISMISSED_WITHOUT_RESULT` 并在弹窗内显示中文指引，不再按 `PICKER_CANCELLED` 静默忽略；并在选择生命周期补充关键诊断日志。
- **清理重复 Capacitor 插件注册**：
  - 移除 `AppDelegate.swift` 中在 `autoRegisterPlugins` 开启时不起作用的 `registerPluginType:` 调用，并将 `capacitor.config.json` 与 CI 配置中的 `packageClassList` 统一收敛为 `["TarvenEnvPlugin"]`。
- **前置拦截非路径文本并中文化路径报错**：
  - `install-location.ts` 新增 `validateInstallPathInput(rawValue, { isIOS })`，在新建实例（`routes/index.tsx`）和迁移（`RelocateInstanceModal.tsx`）提交前直接拦截「我的 iPhone ▸ SillyClient」等界面面包屑名称、相对路径、`..` 上级跳转与链接输入，避免进入启动流程后再暴露底层英文报错；
  - `native-errors.ts` 补全 `PICKER_DISMISSED_WITHOUT_RESULT`、`An absolute local installation path is required`、`Only absolute local paths and credential-free file URLs are supported` 与 `Installation paths cannot be relative or contain parent traversal` 的中文引导提示。
- **未改动 Windows、Android**。
