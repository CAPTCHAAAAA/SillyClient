# SillyClient v1.4.0

> Windows：酒馆窗口改为叠加，启动改走 start-server.bat。Android：手势退出改为返回启动器，实例继续运行。iOS：本版没有安装包。两端都修复了封面图更换。

## 变更内容

**封面**（Windows / Android）

- 修复封面图更换。

**Windows**

- 酒馆窗口改为叠加模式，不关闭主窗口。
- 重写 runtime 层，paths.ts 与 process.ts 大幅简化。
- npm install 直接用 node.exe 执行 npm-cli.js，不走 cmd.exe。
- 启动服务改用 start-server.bat。
- flattenExtractedDir 改为解压前清空目录。
- cmd.exe 改用 process.env.ComSpec 的完整路径。

**Android**

- 手势退出改为返回启动器，实例继续运行。
- 顶部状态栏反方向滑动可返回酒馆。
- 卡片菜单新增「返回酒馆」和「停止实例」。

**iOS**

- 本版没有安装包。

## 下载与校验

- Windows：`SillyClient-Setup-1.4.0.exe`。
- Android：`SillyClient-1.4.0-android.apk`。
- iOS：本版没有安装包。
