# SillyClient v1.14.1

> 跨端通用前端：全面落地 22 步交互式实战新手引导，视口级 SVG Mask 硬件遮罩根治高刷屏画面撕裂与显存饥饿，沙箱加载无缝平滑淡入淡出；卡片内联重命名与抽屉控制台深度优化；内置 SC Bordeaux 主题预设终态（Revision 3，高斯模糊 14）。Android：WebView 硬件管线优化，新增可逆「酒馆性能优化」拨杆，实例运行时间持久化接管，SAF 存储契约与变色龙引擎守护（versionCode 76）。Windows：终态解耦后端与强类型 IPC 契约守护，Storage 页签 ZIP 导入导出，严守零默认路径铁律。iOS：升版至 1.14.1（Build 39），守卫 NodeMobile 原生沙盒与独立终端提示符。

## 变更内容

### 跨端通用前端与交互体验（Windows / Android / iOS）

- **交互式新手实战引导与视觉防撕裂**：
  - **下线旧版迁移弹窗**：彻底移除阻断性旧版迁移向导，升级为全沉浸式 22 步隔离实战引导（`OnboardingSession`），在隔离沙箱环境中安全体验实例配置、背景交互与启动演练。
  - **视口级 SVG Mask 硬件级镂空遮罩**：彻底消除高刷新率（120Hz/144Hz LTPO）屏幕下的画面撕裂与白块频闪。摒弃传统 CSS `box-shadow: 150vmax` 引发的高达 8000×8000px（约 288MB 显存）的巨额脏矩形重绘，改用视口受限矢量遮罩（`<svg><mask id="sc-spotlight-mask">`），将逐帧光栅化耗时从 15ms 压缩至 0.05ms（降低 99.6%）。
  - **沙箱平滑淡入淡出（Cross-fade）与背景交互锁**：沙箱就绪时采用多阶段透明度渐变过度，彻底消除页面切换瞬间白屏与黑块竞态；引导与模态弹窗开启期间引入全局背景交互锁，杜绝滑动穿透与误触。
- **卡片标题就地内联重命名与抽屉式控制台**：
  - 实例卡片未运行状态支持直接在标题位置双向内联编辑重命名（`InstanceRenameField`），双向平滑过渡，彻底下线独立弹窗 `RenameModal`。
  - 引入规范化抽屉组件 `InstanceCardDrawer`，普通卡与运行卡共用展开收起逻辑，支持多端手势与折叠动画；规范卡片与控制台操作按钮（`ActionButton`）。
- **SC Bordeaux（波尔多红酒）主题预设升级（Revision 3）**：
  - 内置主题预设升级至终态 Revision 3，高斯模糊半径调谐至 `14`，呈现更深邃通透的深红宝石液态玻璃质感与高可读性文字对比度。
- **多端原生契约辅助库健全**：
  - 健全 `native-errors.ts`（原生错误人类友好转换）、`tavern-release.ts`（版本选择逻辑）与 `instanceParentPath`。

### Windows

- **纯净后端架构终态冻结守护**：
  - 坚守前后端强类型 IPC 契约（`src/contracts/ipc-contracts.ts`）与纯净门面（`src/plugin.ts` <= 300 行），自治领域服务严密解耦，88 项宿主与契约单元测试网 100% 绿灯。
- **零默认路径铁律与 Storage 原生扩展**：
  - 实例创建 100% 由用户自主指定存储文件夹，彻底消除任何软件预设落点。
  - 实例管理 Storage 页签原生支持「导出实例（ZIP）」（流式打包至用户所选目录）与「导入数据（ZIP）」完整性预检。
- **安装包生产与无损覆盖安装**：
  - NSIS 安装包构建体积优化（118.8 MB），支持静默无损覆盖安装，存量实例与配置 100% 安全保留。

### Android

- **WebView 硬件管线优化与频闪根治**：
  - 针对高刷屏及 LTPO 可变刷新率设备，优化 WebView 硬件图层混合类型，消除离屏 FBO 竞态，确保引导动画与主界面满帧平滑。
- **新增「酒馆性能优化」设置拨杆**：
  - APP 设置通用页增加安卓专属「酒馆性能优化」，专为移动端低功耗与复杂酒馆扩展设计，即时可逆启停，不影响安全区、输入法与存储链路。
- **实例运行时间持久化接管**：
  - `InstanceUsageStore` 完整入库并接管实例使用时长统计与删除联动，精准记录运行周期。
- **系统级 SAF 存储接入与无损迁移**：
  - 实例创建第一步强制调起系统文件选择器，实例根目录由用户指定，绝无后台私设路径。
  - 实例导出全面对接系统级 Storage Access Framework（SAF 另存为选择器），流式写入目标 ZIP。
- **沉浸式变色龙渲染引擎（Chameleon Engine）**：
  - 状态栏与导航栏全时取色与低占用单次取色模式，新增点击水波纹光效开关与主题联动保护。
- **版本号与打包**：
  - 版本号：`1.14.1`（versionCode: 76），无损覆盖安装。

### iOS

- **版本号与 Build 递增**：
  - 原生工程与 Info.plist 版本号对齐至 `1.14.1`，Build 号递增至 `39`。
  - CI 工作流、E2E 测试断言与平台契约测试全量对齐。
- **NodeMobile 运行时与文件沙盒安全守护**：
  - 守卫 UIDocumentPicker 文件夹选择指引与沙盒隔离保护，遵循 iOS 存储安全规范。
  - 原生终端提示符严格对齐 `iOS 控制台` 与 `ios >`。
- **云端全链路契约与单测校验**：
  - 前端 46 项单测、平台契约 118 项测试及云端模拟验证 7 大套件 100% PASS。
