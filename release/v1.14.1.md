# SillyClient v1.14.1

> Windows：同步通用前端 1.14.1 基线，守护纯净解耦后端与强类型 IPC 契约，支持实例 Storage 页签 ZIP 导出/导入。Android：全量同步通用前端，支持卡片内重命名与教程 v4，加固系统 SAF 存储与变色龙渲染（versionCode 76）。iOS：升版至 1.14.1（Build 39），守卫原生沙盒与独立终端提示符。通用前端全面落地卡片标题内联重命名与抽屉式控制台，首屏图文引导升级 v4 架构，全端严守“零默认路径”铁律。

## 变更内容

### 跨端通用前端与交互体验（Windows / Android / iOS）

- **卡片标题就地内联重命名**：
  - 实例卡片未运行状态支持直接在标题位置内联编辑重命名（`InstanceRenameField`），双向平滑过渡，彻底下线独立弹窗 `RenameModal`。
  - 保留输入法 IME 组合键、防重提交、错误拦截与键盘快捷键交互。
- **展开式控制台抽屉与按钮规范**：
  - 引入统一抽屉组件 `InstanceCardDrawer`，普通与运行卡共用展开收起逻辑，支持多端手势与折叠动画。
  - 规范卡片与控制台操作按钮（`ActionButton` / `console-card.css`），统一操作热区与视觉层次。
- **首屏新手引导教程全面重构（v4）**：
  - 接入 21 张高清 WebP 界面教程资产，根据 Android / Windows / iOS / Web 运行宿主自动呈现专属图文说明。
  - 采用 Suspense 懒加载代码分割，不影响应用首屏极速冷启动。
- **多端原生契约辅助库**：
  - 统一补齐 `native-errors.ts`（原生错误人类友好转换）、`tavern-release.ts`（版本选择逻辑）与 `instanceParentPath`。

### Windows

- **纯净后端架构终态冻结守护**：
  - 维持 `src/contracts/ipc-contracts.ts` 强类型 IPC 契约与 `src/plugin.ts` 纯净门面。
  - 88 项宿主与契约单元测试网 100% 绿灯（87 pass, 1 skipped cache, 0 fail）。
- **零默认路径铁律与 Storage 原生扩展**：
  - 保持实例路径 100% 用户自选，不留软件默认落点。
  - 实例管理 Storage 页签原生支持「导出实例（ZIP）」（自选原生保存路径）与「导入数据（ZIP）」预检。
- **安装包生产与升级验证**：
  - NSIS 安装包构建体积优化（119.1 MB），支持静默无损覆盖安装。

### Android

- **系统级 SAF 存储接入与无损迁移**：
  - 实例创建第一步强制调起系统文件选择器，实例根目录由用户指定。
  - 实例导出对接 Storage Access Framework（SAF 另存为选择器），流式写入目标 ZIP。
- **沉浸式变色龙渲染引擎（Chameleon Engine）**：
  - 状态栏与导航栏沉浸式动态取色落地，提供全时取色与低占用单次取色模式。
  - 点击水波纹光效开关与主题联动保护，WebView 线程交互全量加固防崩。
- **版本与测试**：
  - 版本号：`1.14.1`（versionCode: 76）。
  - 24 项 Android 原生单元测试网与 49 项 Release 打包任务全量通过。

### iOS

- **版本号与 Build 递增**：
  - 原生 Info.plist（`native-src` 与 `ios/App/App` 保持 100% SHA-256 逐字节一致）版本号对齐至 `1.14.1`，Build 号递增至 `39`。
  - CI 工作流、E2E 测试断言与平台契约测试全量对齐。
- **文件沙盒与凭据安全守护**：
  - 保留 UIDocumentPicker 文件夹选择指引与沙盒隔离保护。
  - 原生终端提示符严格对齐 `iOS 控制台` 与 `ios >`。
- **云端全链路契约与单测校验**：
  - 前端 46 项单测、平台契约 118 项测试及云端模拟验证 7 大套件 100% PASS。
