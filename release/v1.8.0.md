# SillyClient 1.8.0

本次更新重构了实例管理入口，补充实例级终端与维护能力，并为 Android、Windows 加入 SillyClient 应用版本检查。

## 更新内容

- 重构实例管理菜单，以启动、快照、存储、终端和关于分类组织实例操作，并补充实例搜索、类型筛选与更多操作入口
- 实例终端改为绑定当前实例，在对应实例目录中执行命令；远程实例会明确提示不支持本地终端
- 新增实例设置快照，可保存和移除当前端口与运行配置记录
- 改善实例封面更换流程：Windows 使用临时文件原子替换并清理旧扩展名，避免选择图片后卡住或丢失原封面
- 完善重命名、实例管理与二级菜单的入场和退出动效，统一按钮质感，并修复白天模式下实例操作按钮的不必要反色
- APP 设置的维护页新增“检查新版本”；Android 与 Windows 启动后会静默检查 SillyClient Release，也可手动重试
- 更新检查在 GitHub 直连不可用时依次尝试代理与 jsDelivr 元数据；失败不会阻塞应用启动，也不会自动下载安装
- Android、Windows 与网页演示同步使用同一套 1.8.0 React 控制台构建

## 下载

- `SillyClient-Android-v1.8.0.apk`
- `SillyClient-Windows-v1.8.0.exe`

Android 支持 Android 8.0 及以上的 arm64 设备。Windows 支持 Windows 10 / 11 x64。
