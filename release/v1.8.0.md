# SillyClient 1.8.0

本次更新重构了实例管理入口，补充实例级终端与维护能力，并为 Android、Windows 加入 SillyClient 应用版本检查。现有 `v1.8.0` Release 已补入 Windows 实例生命周期维护修复，版本号与 Android 安装包保持不变。

## 本次维护修复

- 修复 Windows 更换实例插图后无法显示、继续使用旧缓存或重启后丢失的问题；新插图通过应用内部安全地址加载，并兼容迁移旧版 `capacitor-file:///` 记录
- 修复 Windows 删除实例时目录、插图、日志或临时文件残留的问题；删除前会停止对应服务并释放端口与文件占用，随后重试并校验目录已彻底移除
- 修复 Windows 指定目标路径后仍在默认位置生成实例的问题；现在会区分父目录、空目录与已有 SillyTavern 目录，并持久记录实例的真实路径
- 修复 Windows 无法可靠显示创建时间、上次使用时间与累计使用时长的问题；累计使用现在按实际运行时间结算，不再误用存储占用数据
- 改善 Windows 重启后的实例发现与恢复，包含使用自定义安装路径创建的实例
- 修复应用退出阶段仍向已销毁窗口发送 IPC 所导致的崩溃
- 保持 Android 现有实例与插图逻辑不变，仅补充 Windows 平台所需的桥接与兼容处理

## 1.8.0 更新内容

- 重构实例管理菜单，以启动、快照、存储、终端和关于分类组织实例操作，并补充实例搜索、类型筛选与更多操作入口
- 实例终端改为绑定当前实例，在对应实例目录中执行命令；远程实例会明确提示不支持本地终端
- 新增实例设置快照，可保存和移除当前端口与运行配置记录
- 完善重命名、实例管理与二级菜单的入场和退出动效，统一按钮质感，并修复白天模式下实例操作按钮的不必要反色
- APP 设置的维护页新增“检查新版本”；Android 与 Windows 启动后会静默检查 SillyClient Release，也可手动重试
- 更新检查在 GitHub 直连不可用时依次尝试代理与 jsDelivr 元数据；失败不会阻塞应用启动，也不会自动下载安装
- Android、Windows 与网页演示同步使用同一套 1.8.0 React 控制台构建
