# SillyClient v1.8.0

> Windows：修复插图、删除残留、自定义路径和使用时长。Android：安装包与实例、插图逻辑保持原 Release（versionCode 12）。iOS：本版没有安装包。两端共用新的实例管理菜单和版本检查。

## 变更内容

**界面**（Windows / Android）

- 重构实例管理菜单，以启动、快照、存储、终端和关于分类组织实例操作，并补充实例搜索、类型筛选与更多操作入口。
- 实例终端改为绑定当前实例，在对应实例目录中执行命令。远程实例会明确提示不支持本地终端。
- 新增实例设置快照，可保存和移除当前端口与运行配置记录。
- 完善重命名、实例管理与二级菜单的入场和退出动效。统一按钮质感，并修复白天模式下实例操作按钮的不必要反色。
- 维护页新增「检查新版本」。启动后静默检查 SillyClient Release，也可手动重试。GitHub 直连不可用时依次尝试代理与 jsDelivr。失败不阻塞启动，也不自动下载安装。
- 两端与网页演示使用同一套 1.8.0 React 控制台构建。

**Windows**

- 修复更换实例插图后无法显示、继续使用旧缓存或重启后丢失的问题。新插图通过应用内部安全地址加载，并兼容旧版 `capacitor-file:///` 记录。
- 修复删除实例时目录、插图、日志或临时文件残留的问题。删除前停止对应服务并释放端口与文件占用，随后重试并校验目录已移除。
- 修复指定目标路径后仍在默认位置生成实例的问题。现在会区分父目录、空目录与已有 SillyTavern 目录，并记录实例的真实路径。
- 修复创建时间、上次使用时间与累计使用时长。累计使用按实际运行时间结算，不再误用存储占用数据。
- 改善重启后的实例发现与恢复，包含使用自定义安装路径创建的实例。
- 修复应用退出阶段仍向已销毁窗口发送 IPC 所导致的崩溃。
- 安装包尚未配置 Authenticode 代码签名。

**Android**

- 实例与插图逻辑保持不变。
- 版本 1.8.0（versionCode 12）。安装包与原 Release 保持一致。

**iOS**

- 本版没有安装包。
