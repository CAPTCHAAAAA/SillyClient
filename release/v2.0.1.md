# SillyClient 2.0.1

## 1. 核心更新公告画布 (What's New)

- **全屏虚化沉浸画布**：
  - 更新后首次启动自动呈现全新版本主要更新全屏虚化画布（采用柔焦毛玻璃遮罩彻底虚化底座主界面）。
  - 支持在「APP 设置 - 维护」以及本地调试板中随时重新打开查看。
- **纯正轻拟物扁平与极简无边框设计**：
  - 彻底去除弹窗更新卡片与顶部版本号的生硬封闭线框，采用设置页同款低饱和轻微色差区域（4%~6% 透明度填充）进行柔和分区。
  - 顶部版本号标签与右下角操作按钮统一采用 `rounded-xl` 方圆韵律与无边框色差设计，视觉纯净通透、毫无压迫感。
- **直观聚焦的三维更新概述**：
  - 更新说明全面精简，直达三大核心维度：可以使用的新功能（数据迁移与原地接管）、可以看到的新更新（全域平滑过渡与视觉升级）、可以体验到的新优化（120Hz 硬件高刷与深度休眠）。

## 2. 界面动效与视觉韵律完善

- **全域胶囊切换平滑过渡**：
  - 为设置抽屉面板（通用 / 数据 / 维护）以及实例管理弹窗（启动 / 快照 / 存储 / 终端 / 关于）全面接入同位驻留 DOM、微位移升降与高斯模糊虚化交叉溶变动效。
  - 容器尺寸自适应平滑伸缩，消除切换时的瞬态跳跃。
- **设置页列表韵律规范**：
  - 优化设置项链接排版，统一为极简发丝级底部横线与微内高光质感，保持克制留白与低调工具界面风格。
