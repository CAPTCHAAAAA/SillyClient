# SillyClient v2.0.1

> Windows：同步更新说明画布和设置、实例管理的切换动效。Android：同样同步。iOS：本版没有安装包。

## 变更内容

**界面**（Windows / Android）

- 更新后第一次启动会打开更新说明。之后可在「APP 设置 → 维护」再打开。
- 更新说明卡片和版本号去掉封闭线框，改为低饱和色块分区。
- 更新说明收成三类：新功能、界面更新、性能优化。
- 设置抽屉和实例管理弹窗使用同一套进入和退出动效。切换时容器高度跟着变。
- 设置列表保留细底边，不再加封闭外框。

**iOS**

- 本版没有安装包。
