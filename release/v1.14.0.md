# SillyClient v1.14.0

> Windows：同步通用前端解耦重构基线，保持纯净解耦后端与强类型 IPC 契约，支持实例 Storage 页签 ZIP 导出/导入。Android：全量同步通用前端解耦基准，落地沉浸式变色龙渲染引擎（全时/单次取色模式与点击光效联动），自愈酒馆扩展更新检测（versionCode 75）。iOS：同步通用前端解耦基准（Build 38），完善文件夹沙盒选择操作引导，保持 iOS 控制台独立提示符。三端全面移除新版本内容公告弹窗，物理拖拽与终端材质焕新，全端严守“零默认路径”铁律。

## 变更内容

### 跨端通用前端与交互体验（Windows / Android / iOS）

- **应用内版本更新公告全面退役**：彻底移除阻断操作的“主要更新”全屏弹窗与各级入口，首次安装、版本升级与日常冷启动均不再受公告阻断，纯粹专注酒馆控制与实例调度。
- **物理卡片拖拽与底层动态采样**：
  - 重构卡片拖拽长按抬起与吸附动效（`useFrozenCoverPlate`），采用 C2 连续五次曲线平滑过渡，彻底解决快速拖拽或归位时的画面抽搐与边缘漏光问题。
  - 针对多端硬件优化 GPU 合成层，拖拽重排全程保持高帧率流畅。
- **统一终端（Terminal）外壳与质感**：
  - 控制台、实例运行卡与弹窗管理面板统一采用深色毛玻璃材质井（`TerminalWell`）。
  - 引入开源等宽字体 `Maple Mono`，命令输入区、日志排版行高与字号控件严格居中对齐，支持自由拖拽与边框缩放手柄。
- **前端架构自治化与解耦**：
  - 剥离 `useBackgroundMode` 独立背景钩子、`useManagePanelLayout` 响应式布局模块，全面清理废弃组件（如 `ActivityCapsule`）与未引用资源。
  - 严格实施 TypeScript 未使用符号拦截，跨端前端代码 0 告警、0 冗余。

### Windows

- **纯净后端架构终态冻结守护**：
  - 前后端基于 `src/contracts/ipc-contracts.ts` 建立绝对强类型 IPC 契约，彻底清除弱类型强转。
  - `src/plugin.ts` 保持轻量纯净门面（<=300行），细分职责完全下沉至自治领域服务（`src/*.ts`），88 项宿主与契约单元测试网 100% 绿灯。
- **零默认路径铁律与 Storage 原生扩展**：
  - 创建实例 100% 由用户自主指定存储文件夹，彻底消除任何软件预设落点。
  - 实例管理 Storage 页签原生支持「导出实例（ZIP）」（流式打包至用户所选目录）与「导入数据（ZIP）」完整性预检，平滑迁移移动端与备份数据。
- **安装包生产与覆盖体验**：
  - NSIS 安装包构建体积优化（118.9 MB），支持静默无损覆盖安装，存量实例与配置 100% 安全保留。

### Android

- **系统级 SAF 存储接入与无损迁移**：
  - 实例创建第一步强制调起系统文件选择器，实例根目录由用户指定，无任何后台私设路径。
  - 实例导出全面对接系统级 Storage Access Framework（SAF 另存为选择器，`ACTION_CREATE_DOCUMENT`），流式写入目标 ZIP，杜绝私设 `Download/` 目录。
  - 实例管理 Storage 页签完整支持 ZIP 导入与单实例无损换盘迁移。
- **沉浸式变色龙渲染引擎（Chameleon Engine）**：
  - 状态栏与导航栏沉浸式动态取色落地，提供「全时取色」与「单次取色」低占用模式；单次模式在 DOM 样式沉淀后自动注销全部监听与定时器，实现后续滑动 0 采样、0 性能负载。
  - 新增点击水波纹光效开关与主题联动保护，WebView 线程交互全量加固防崩。
- **酒馆扩展更新检测自愈**：
  - 进程内原位桥接 `simple-git` 至纯 JS 实现，注入多源 Git HTTP 镜像回退链，自动识别并自愈历史版本中无 `.git` 结构的扩展目录，解决更新检测与按钮缺失。
- **版本与测试**：
  - 版本号：`1.14.0`（versionCode: 75）。
  - 24 项 Android 原生单元测试网与 49 项 Release 打包任务全量通过，采用官方历史签名证书无缝升级。

### iOS

- **原生宿主与运行时字节级对齐**：
  - `SillyClient_iOS` 原生工程（`TarvenEnvPlugin` / `TavernViewController` / `Info.plist`）与主仓保持 100% SHA-256 逐字节一致。
  - 原生终端提示符严格对齐 `iOS 控制台` 与 `ios >`，杜绝跨平台平台字符串串台。
- **文件沙盒与凭据安全守护**：
  - 保留 UIDocumentPicker 文件夹选择指引与沙盒隔离保护，遵循 iOS 存储安全规范。
  - 保留实例访问密码作废前通知时序，完善移动端局域网访问提示。
- **云端全链路契约与单测校验**：
  - 前端 46 项单测、平台契约 118 项测试及云端模拟验证 7 大套件 100% PASS，产出标准化未签名 IPA（Build 38）。
