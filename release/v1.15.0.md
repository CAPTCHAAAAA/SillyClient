# SillyClient v1.15.0

> Windows：接入问题反馈与界面缩放，更新设置和实例管理面板。Android：同步上述界面更新，修复在线创建历史版本时的 `.nomedia` 解压冲突（versionCode 77）。iOS：同步问题反馈、缩放与面板更新，整合文件夹选择和安装路径修复（Build 51）。

> **2026-11-18 紧急更新**：Windows / iOS 安装包已补齐最新 SC Bordeaux 主题预设（Revision 3），修复新建实例选择主题时因预设版本不一致而失败的问题。版本仍为 `1.15.0`；已下载早先 Windows / iOS 包的用户请重新下载本页附件。

## 变更内容

**问题反馈与界面**（Windows / Android / iOS）

- 新增全局问题反馈窗口：展示错误信息，可填写补充说明后提交至 Sentry，并返回反馈编号；提交前对路径、凭据等诊断内容进行脱敏。
- 反馈发送失败时支持重试，也可通过「打开草稿」带入诊断内容，在 GitHub 上继续提交问题。
- 背景设置新增「界面缩放」，支持 90%–150% 调整并保存偏好；同步修正弹窗、终端和新手引导在缩放后的定位。
- 修复新手引导准备期间偶发黑屏或无法继续的问题，增加超时恢复与重试；准备期间可返回首页。
- 恢复背景设置、APP 设置与实例管理面板的背景虚化；弹窗关闭时，遮罩、虚化与面板同步退场，退出后恢复首页交互。
- 统一设置项切换与弹窗溶解过渡，调整背景图片导入按钮、界面缩放选项与基础／自定义设置的交互表现。
- 三端内置 SC Bordeaux 主题预设统一为 Revision 3；新建实例选择该预设时使用新版主题，已有实例的主题设置保持原样。

**Windows**

- 桌面端接入统一的问题反馈流程，保留 Windows 控制台、实例目录选择与 ZIP 导入导出。
- 版本更新为 `1.15.0`。

**Android**

- 修复在线下载历史版本或非内置酒馆源码时，压缩包自带的 `.nomedia` 与临时目录中的同名文件冲突、导致创建失败的问题。
- 同步问题反馈、界面缩放、引导启动与浮层更新，保留系统目录选择和 ZIP 导入导出。
- 版本更新为 `1.15.0`（versionCode `77`）。

**iOS**

- 整合 `1.14.2`–`1.14.5` 的文件夹选择、目录授权恢复、实例名称与路径校验修复；异常关闭文件选择器时给出提示。
- 创建或迁移前拦截「我的 iPhone ▸ …」等文件界面显示名称、相对路径与无效链接，避免将它们作为安装路径继续执行。
- 同步问题反馈、界面缩放、引导启动与浮层更新，保留 iOS 控制台及 NodeMobile 运行时。
- 版本更新为 `1.15.0`（Build `51`）。
