# SillyClient 1.11.0

> 本版包含跨平台 ZIP 导入启动修复与运行时鲁棒性增强（等待多平台齐备后一同发布）。

## 核心变化

### 1. 跨平台 ZIP 数据迁移与导入强化
- **失效跨平台依赖锁自动重置**：智能检测从 Android、Termux 或其他移动端环境备份的酒馆 ZIP 压缩包；若其中包含移动端绝对路径（如 `/data/com.sillyclient/...`）或移动端相对引用的失效 `package-lock.json`，在导入与迁移阶段自动重置并重新按目标平台原生环境解析依赖，彻底解决跨端迁移后依赖解析死循环与安装卡死问题。
- **孤儿标记清理**：迁移过程中自动清理移动端遗留的瞬态标志（如 `.sillyclient-dependencies-pending`、`.sillyclient-prebuilt-lib` 等），杜绝实例陷入反复失败循环。

### 2. 依赖安装交互与日志流体验优化
- **长流程心跳反馈**：在 Windows 原生依赖安装（npm install）过程中增加 10 秒定时心跳日志（`依赖安装中（已耗时 XXs，请耐心等待）...`），并在向导进度提示中明确标注首次安装需 1~3 分钟，消除长流程静默造成的假死感。
- **日志分级智能降级**：修复 npm 日志级别识别机制，将第三方库的 deprecation 警告（`npm warn`）、通知（`npm notice`）与 HTTP 请求（`npm http`）智能映射为普通的 `info` 级别，仅 `npm ERR!` 输出为红色错误，杜绝常规编译告警被误报为启动故障。

---

## 兼容性

- Android：Android 8.0（API 26）及以上，arm64 设备。
- Windows：Windows 10 / 11（x64）。
- iOS：iOS 14.0 及以上，arm64 设备。
