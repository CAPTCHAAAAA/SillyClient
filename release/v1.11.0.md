# SillyClient 1.11.0

> 本版汇总自 1.10.0 以来的用户可见更新。下文代码块为实际改动摘要（已按可读性删减上下文）。

## 核心变化

### 1. 实例存放目录改由用户指定（三个入口统一）

新建实例、复制迁移、存储迁移三处均须先选择存放文件夹，实例以该文件夹的一级子目录形式创建
（`<存放文件夹>/<实例名>`）；迁移与存储迁移的目标目录仅可通过目录选择器指定（输入框只读）。
应用不再内置任何实例存放位置，`默认存储路径 / 恢复默认路径 / 默认目录 (instances/)` 入口已移除。

三个入口共用同一条解析：先把所选目录登记为实例根，再取它的一级子目录作为实例目录。

```tsx
// web/capacitor-ui/src/routes/index.tsx
const resolveInstanceParent = useCallback(async (
  rawValue: string, emptyMessage: string, instanceName: string,
): Promise<string> => {
  const parent = instanceParentPath(rawValue);
  if (!parent) throw new Error(emptyMessage);
  try {
    await TarvenEnv.setInstancesRoot({ path: parent });
  } catch (error) {
    const reason = humanizeNativeError(error instanceof Error ? error.message : String(error));
    throw new Error(`该文件夹不能作为实例存放位置：${reason}`);
  }
  return buildInstanceSubfolder(parent, instanceName);
}, []);
```

必选项校验（本地创建；迁移复制模式同规则）：

```tsx
if (newInstanceMode === "local" && !newInstanceDir.trim()) {
  setNewInstanceError("请先选择实例存放文件夹（必选）：点击「浏览」选择后，实例会创建在该文件夹内");
  return;
}
if (newInstanceMode === "import" && migrationAccessMode === "copy" && !migrationCustomDest.trim()) {
  setNewInstanceError("请先选择迁移目标文件夹（必选）：点击「浏览」选择后，数据会迁移到该文件夹内");
  return;
}
```

手输与「浏览」同义（不再存在"整条路径当作实例目录本身"的模式）：

```tsx
const handleSetNewInstanceDir = useCallback((value: string) => {
  const clean = value.replace(/^["']|["']$/g, "").trim();
  setNewInstanceDir(clean);
  setNewInstancePathMode("root");   // 手输 = 存放文件夹（实例根）
  setNewInstanceError(null);
  directoryPickerGeneration.current += 1;
}, []);
```

迁移目标字段只读，只能通过系统目录选择器指定：

```tsx
<input
  type="text"
  value={migrationCustomDest}
  readOnly
  placeholder="点击「浏览」选择目标文件夹"
/>
```

授权时机同步调整：只在选择目录时按需申请，启动阶段不再有授权提示。

```kotlin
// app/src/main/java/com/sillyclient/plugin/TarvenEnvPlugin.kt
act.runOnUiThread {
    if (purpose == "installation" && !requestStorageAccess(call)) return@runOnUiThread
    startActivityForResult(call, intent, "pickDir")
}
```

### 2. Android 稳定性修复

**注册表历史路径导致读取失败（迁移报错、删除崩溃）。** 注册表读取时逐条校验实例路径是否落在
"允许根"内；早期版本创建于旧默认位置的实例会使整张注册表读取抛异常。现把历史默认位置永久纳入
允许根（目录当前不存在也算），范围外路径仍拒绝：

```kotlin
// app/src/main/java/com/sillyclient/runtime/RuntimePaths.kt
// Historical default instance locations stay accepted no matter which
// root is configured now, and whether or not the directory currently exists.
val legacyDefaults = listOfNotNull(
    File(files, "instances"),                                  // 旧私有区
    try { android.os.Environment.getExternalStorageDirectory() } catch (_: Exception) { null }
        ?.let { File(it, "SillyClient/instances") },            // 旧公共默认根
    externalFiles?.let { File(it, "instances") }                // 旧应用外置区
)
sharedRoots + legacyDefaults
```

```kotlin
// app/src/test/java/com/sillyclient/runtime/InstallLocationRegistryTest.kt（新增回归测试）
@Test
fun configuredRootStillAcceptsHistoricalDefaultDirectoriesAsInstanceLocations()
```

**前台服务启动超时导致进程被系统终止。** `startForegroundService()` 的承诺必须在时限内兑现，
且服务确认升格前不得停止：

```kotlin
// app/src/main/java/com/sillyclient/runtime/KeepAliveService.kt
override fun onCreate() {
    super.onCreate()
    promoteToForeground()        // 尽快兑现 startForegroundService() 的承诺
}

private fun promoteToForeground() {
    try { startForeground(NOTIFICATION_ID, buildNotification()) }
    catch (error: Exception) { runCatching { stopSelf() } }
}

private fun stopServiceWhenSafe(context: Context) {
    if (!serviceStarted) { stopRequested = true; return }   // 未升格前绝不 stopService
    runCatching { context.stopService(Intent(context, KeepAliveService::class.java)) }
}
```

**向导字段语义不一致导致的嵌套路径报错。** 根更新失败时直接给出中文原因并清空输入，不再继续执行：

```ts
// web/capacitor-ui/src/lib/native-errors.ts
const NATIVE_ERROR_HINTS: Array<[RegExp, string]> = [
  [/Default installations must be direct children of the instance root/i,
    "该位置在实例存放文件夹的子文件夹里；请选择存放文件夹本身，或实例之外的文件夹"],
  [/Custom installation destinations must be new or empty/i,
    "该文件夹已存在且不为空；请选择一个新文件夹"],
];
```

**实例管理面板窄屏下按钮被压缩为竖排文字**（导出 ZIP 等行）：

```diff
- "motion-control h-8 rounded-xl px-3 text-[11px] font-medium"
+ "motion-control h-8 flex-shrink-0 whitespace-nowrap rounded-xl px-3 text-[11px] font-medium"
```

### 3. Android 性能与后台行为

- 实例创建改为共享依赖目录（`<存放文件夹>/node_modules`）自动铺设：首个实例完成后，后续实例创建不再逐实例解压依赖。
- 依赖解包改为系统 tar 分组并行（按顶层包分组、多进程并发排空输出），达平台单文件写入下限：

```kotlin
// app/src/main/java/com/sillyclient/runtime/TarGroupExtractor.kt
// 每个分组进程由独立等待线程并发排空 stdout —— 逐个等待会让其余 tar
// 阻塞在 pipe_write，提取被静默串行化。
groups.map { group -> pool.submit { runTar(group, targetDirectory) } }
```

- 首次创建时预热前端库编译缓存并在后续实例复用，消除每个实例首次启动的重复编译。
- 实例重命名为同父目录原子改名，不复制数据；删除为原子提交（文件管理器中即时消失）加后台回收：

```kotlin
// 重命名：同父目录原子移动 + 登记表一次提交，无 staging、无复制
Files.move(source.toPath(), target.toPath(), StandardCopyOption.ATOMIC_MOVE)
```

- 长时间操作改由数据同步前台服务与 Doze 白名单承载，熄屏或切换应用不再中断：

```xml
<service android:name=".runtime.KeepAliveService"
    android:exported="false"
    android:foregroundServiceType="dataSync" />
```

- 存储读写去冗余：安装暂存与依赖目录跳过媒体库逐文件索引，创建与删除的元数据开销显著下降。

### 4. iOS 安全加固与时序调度

- 运行时根路径校验按 Darwin `/private` 规范化等价性判定，修复真机 `Unsafe authorized runtime root`，
  同时保持逃逸拦截：

```swift
// Darwin 沙盒将 Documents 解析为 /var/mobile/...，而 /var 是指向 /private/var 的软链；
// 校验前对两侧做 /private 规范化等价比较。
func canonicalRuntimeRoot(_ url: URL) -> URL
```

```javascript
// native-src/Resources/ios-supervisor.mjs
const isSafeRoot = r => {
    if (typeof r !== 'string' || !path.isAbsolute(r)) return false;
    let real;
    try { real = fs.realpathSync(r); } catch { return false; }
    if (real === r) return true;
    const stripPrivate = s => (s.startsWith('/private/') ? s.slice('/private'.length) : s);
    return stripPrivate(real) === stripPrivate(r);
};
if (!isSafeRoot(root)) {
    throw new Error('Unsafe authorized runtime root');
}
```

- 运行时失败标记文件与 Worker 通信时序：先同步写入 `server-failed.json` 再发送 `parentPort.postMessage`，杜绝空文件读取竞争异常：

```javascript
// native-src/ios-loader.mjs
function reportRuntimeFailure(error) {
    try {
        fs.writeFileSync(path.join(runtimeDir, 'server-failed.json'), JSON.stringify({ error: String(error) }));
    } catch {}
    if (parentPort) {
        parentPort.postMessage({ type: 'server-failed', error: String(error) });
    }
}
```

- 新增有界文件访问守卫与 Worker 工作目录校验，越界访问直接拒绝。
- 运行时所有权与实例操作改为事务化执行，失败回滚并保留恢复计划（隔离与恢复流程）。
- 原生库锁定到已验证的不可变上游提交，Yams 等依赖固定到已发布版本。
- 原生桥关闭 payload 日志；运行日志按实例隔离。
- 安全用例（令牌重放拒绝、监听器关闭、隔离恢复）纳入全量自动化测试与 CoreSimulator 端到端验证。
- 修复：模拟器上文档选择器崩溃、重入式启动冲突、实例标识 ASCII 化（选择器禁用复制模式）、
  WKWebView 导航取消重试死循环、酒馆 DOM 就绪探测超时。

### 5. Windows

- 跨端 ZIP 导入：检测来自 Android/Termux 等环境的失效 `package-lock.json` 与移动端绝对路径并自动重置依赖；
  清理移动端遗留标记：

```ts
const RETIRED_MARKERS = [".sillyclient-dependencies-pending", ".sillyclient-prebuilt-lib"];
```

- 依赖安装过程每 10 秒输出心跳日志；`npm warn/notice/http` 归类为普通信息，仅 `npm ERR!` 标红。
- 与移动端同构的可配置实例存储根目录（含绝对路径校验，禁止直接使用磁盘根目录）：

```ts
setInstancesRoot(options?: { path?: string }): Promise<{ instancesRoot: string; configured: boolean }>
```
