# SillyClient 1.11.0

> 本版汇总自 1.10.0 以来的全部用户可见更新。

## 核心变化

### 1. 实例存放目录全面改由用户指定（核心数据模型解耦）
- **按需自主选择**：新建实例、复制迁移、存储迁移三大入口全面重构，创建实例前必须先指定存放文件夹（必选项），实例将自动作为该文件夹的一级子目录创建（`<存放文件夹>/<实例名>`），用户拥有绝对的数据掌控权。
- **彻底告别内置默认路径**：移除以往软件内置的 `instances/` 默认私有路径以及相关“恢复默认路径”逻辑，杜绝应用更新卸载或系统清理可能导致的数据误删风险。
- **目标路径严格防呆**：迁移与存储迁移的目标目录仅支持通过原生目录选择器选取，手输与浏览逻辑统一并前置校验，从根本上杜绝嵌套路径与非法目录。
- **精细化权限按需申请**：Android 端取消应用启动阶段的粗粒度存储授权提示，严格仅在用户点击「浏览」选择存储目录时按需触发系统权限申请。

### 2. Android 稳定性与异常容错修复
- **历史注册表向下兼容**：注册表加载链路新增历史默认路径兼容容错，即使设备上残留早期版本创建于旧默认位置的历史实例，也能平滑读取与识别，彻底消除升级后出现的迁移报错或注册表崩溃。
- **前台保活服务超时防护**：重构 `KeepAliveService` 生命周期调度，严格保证在系统限定时限内完成前台服务升格，并确保在服务确认升格前拦截意外终止请求，彻底解决高版本 Android 后台服务启动超时被系统终止的问题。
- **原生异常友好中文提示**：全面梳理向导底层错误语义，针对目标目录已被占用、嵌套选在实例内部等异常场景，提供精准清晰的中文引导提示并自动重置异常状态。
- **移动端窄屏排版适配**：优化实例管理面板在小屏及折叠屏设备上的布局表现，修复导出 ZIP 与操作行按钮在特定窄屏下被挤压变形的显示问题。

### 3. Android 性能重构与后台运行强化
- **共享依赖底座自动铺设**：实例创建机制重构，支持在存放目录自动铺设共享依赖（`node_modules`）；首个实例完成部署后，后续新实例无需重复解压依赖，创建耗时大幅缩减。
- **Tar 分组并发解包**：依赖解包引擎升级为多进程并发分组排空机制，大幅突破单线程 I/O 吞吐瓶颈，依赖展开速度提升数倍。
- **编译缓存全局预热**：首次创建实例时自动预热前端库编译缓存并在后续实例间智能复用，消除以往每个实例首次启动时的重复编译等待。
- **原子级重命名与删除**：实例重命名升级为同父目录文件系统原子移动，零数据拷贝即时生效；实例删除采用原子解绑与后台异步清理，文件管理器内即时刷新。
- **系统级长时间任务保活**：长时间数据操作与实例运行由专用数据同步前台服务承载，配合 Doze 电池优化白名单保护，息屏或前后台切换不再中断运行。
- **精简存储 I/O 开销**：安装暂存与依赖目录默认跳过系统媒体库逐文件扫描索引，大幅减少海量小文件元数据读写消耗。

### 4. iOS 平台安全架构与真机加固
- **Darwin 路径规范化修复**：针对 iOS 沙盒底层 `/var` 到 `/private/var` 的软链接特性，引入等价性规范化校验机制，彻底解决实体机创建实例时误报 `Unsafe authorized runtime root` 的故障。
- **严格沙盒越界防御**：新增有界文件访问守卫与 Worker 运行环境深度校验，严密拦截路径穿越与沙盒逃逸行为。
- **实例生命周期事务化**：运行时实例所有权与底层生命周期操作全面接入事务化机制，遭遇异常时自动回滚并提供隔离与故障恢复保护。
- **上游依赖锁定与隐私增强**：全部 Native 依赖锁定到经过不可变校验的安全版本；全面关闭原生桥 Payload 调试日志，运行日志按实例独立切分隔离。
- **多项实体机与体验修复**：修复系统文档选择器崩溃、重入启动冲突、WKWebView 页面重试死循环以及酒馆 DOM 探针就绪超时等问题。

### 5. Windows 平台体验优化与依赖诊断
- **智能跨端 ZIP 导入**：自动识别并清理从 Android / Termux 等移动端迁移过来的无效依赖锁（`package-lock.json`）与历史标记文件，杜绝跨平台导入时引起的依赖死锁与启动异常。
- **依赖安装心跳反馈与日志分级**：长耗时依赖安装过程中每 10 秒输出进度心跳提示，并将 npm 日志智能分级（常规警告降为普通提示，仅严重错误标红），告别“卡死”假象。
- **对齐支持自定义存储根目录**：对齐移动端支持自定义默认实例存储根目录，有效隔离安装包更新与实例数据。

---

## 兼容性

- Android：Android 8.0（API 26）及以上，arm64 设备。
- Windows：Windows 10 / 11（x64）。
- iOS：iOS 14.0 及以上，arm64 设备。
