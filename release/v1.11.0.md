# SillyClient v1.11.0

> Windows：导入手机端 ZIP 时重置失效依赖，并支持配置实例存储根。Android：修复注册表历史路径和前台服务超时，创建改为共享依赖目录（versionCode 69）。iOS：修复真机运行时根路径校验，补上文件访问守卫（Build 29）。三端新建、复制迁移、存储迁移都必须先选文件夹，不再有默认位置。

## 变更内容

**实例存放目录**（Windows / Android / iOS）

- 新建实例、复制迁移、存储迁移都必须先选择存放文件夹。实例创建在该文件夹的一级子目录里。
- 迁移目标只能通过目录选择器指定，输入框只读。手输和「浏览」都表示实例根，不再把整条路径当作实例目录本身。
- 去掉默认存储路径、恢复默认路径和默认目录 `instances/`。
- 没选文件夹就明确提示，不会继续创建或迁移。
- 只在选择目录时申请存储权限，启动阶段不再提示授权。

**Windows**

- 导入来自 Android 或 Termux 的 ZIP 时，失效的 `package-lock.json` 和移动端绝对路径会重置依赖，并清理移动端遗留标记。
- 依赖安装每 10 秒输出心跳。`npm warn`、`notice`、`http` 记为普通信息，只有 `npm ERR!` 标红。
- 实例存储根可以配置。校验绝对路径，禁止直接使用磁盘根目录。

**Android**

- 读取注册表时把历史默认位置纳入允许根，目录当前不存在也算。范围外的路径仍然拒绝。早期实例不再让整张注册表读取失败。
- 前台服务在创建时尽快升到前台。确认升格之前不停止服务。
- 向导里的路径不合法时，直接给出中文原因并清空输入，不再继续执行。
- 实例管理面板在窄屏上不再把导出等按钮压成竖排文字。
- 创建改为使用存放文件夹下的共享 `node_modules`。第一个实例装完后，后面的实例不再各自解压依赖。
- 依赖按顶层包分组，用系统 tar 并行写入。
- 首次创建预热前端库编译缓存，后续实例复用，避免每个实例第一次启动都重新编译。
- 同一目录内重命名改为原子改名，不复制数据。删除先从文件管理器消失，再在后台回收。
- 长时间操作改由数据同步前台服务和 Doze 白名单承载，熄屏或切走不再中断。
- 安装暂存和依赖目录跳过媒体库逐文件索引。
- 版本 1.11.0（versionCode 69）。

**iOS**

- 运行时根路径按 Darwin `/private` 做等价判断，修复真机 `Unsafe authorized runtime root`。越界访问仍然拒绝。
- 失败时先写好失败标记，再通知 Worker，避免读到空文件。
- 增加有界文件访问守卫，并校验 Worker 工作目录。
- 运行时所有权和实例操作改为事务执行。失败会回滚，并保留恢复计划。
- 原生库锁定到已验证的上游提交。Yams 等依赖固定到已发布版本。
- 原生桥不再记录 payload 日志。运行日志按实例隔离。
- 修复模拟器上文档选择器崩溃、重复启动冲突、实例标识非 ASCII、页面导航取消后的重试死循环，以及酒馆页面就绪探测超时。
- 版本 1.11.0（Build 29）。
