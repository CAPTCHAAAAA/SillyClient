# SillyClient v1.14.4

> iOS 紧急修复版（`1.14.4` / Build `49`）：在 `v1.14.3` 基础上继续修复“部分用户可用、留空/中文实例名或外置目录仍创建失败”的分化故障——恢复 iOS 实例安全目录 ID 归一化，并将系统文件选择器的安全作用域获取提前至 `didPickDocumentsAt` 主线程同步完成。本版为紧急补丁，仅更新 iOS，连续跳过 Windows 与 Android（继续使用 [`v1.14.1`](https://github.com/CAPTCHAAAAA/SillyClient/releases/tag/v1.14.1)，后续统一整合）。

## iOS 修复

- **修复留空、中文与含空格实例名创建实例失败**：
  - 恢复 iOS 端在创建实例时通过 `normalizeInstanceIdentity(...)` 生成严格满足 `^[A-Za-z0-9_-]{1,128}$` 的原生实例标识（重名时使用 `-${counter++}`），同时完整保留用户填写的中文/自定义展示名称，解决自 `v1.14.0` 以来默认名称（「新实例」）、中文或空格名称直接触发 `An explicit valid instance identity is required` 报错的问题。
- **消除外部目录选择器返回时的安全作用域授权竞争**：
  - 在 `TarvenEnvPlugin` 的 `documentPicker(_:didPickDocumentsAt:)` 回调返回给系统 UIKit 前，主线程同步调用 `startAccessingSecurityScopedResource()` 锁定临时权限（`preScoped`），再交由后台队列执行 `NSFileCoordinator` 协调与书签持久化，防止系统销毁远程文件选择器会话时提前收回「我的 iPhone」/ iCloud 目录授权。
- **优化选择器呈现顺序与非安装入口默认目录**：
  - 先配置 `modalPresentationStyle = .formSheet` 再绑定 `presentationController?.delegate = self`，确保模态手势取消监听稳定生效；
  - 仅在选定实例安装根目录（`installDir`）时定位默认目录，封面图片、备份压缩包与文本读取不再强制固定进入应用沙盒 `Documents`。
- **补全错误翻译与统一诊断出口**：
  - `native-errors.ts` 新增实例标识规范错误中文提示，并在实例创建、启动与迁移目录选择错误出口统一接入 `humanizeNativeError(...)`。
- **未改动 Windows、Android**。
