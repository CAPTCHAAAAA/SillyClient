# SillyClient v1.15.1

> 三端同步通用前端更新（版本 `1.15.1`，Android versionCode `78`，iOS Build `52`）：实例管理面板升级一体 SVG 文件夹页签与 780ms 刚性同向平切转场，竖屏顶部实例卡改用 1:1 方卡，完善缩放手柄悬停反馈并收敛状态轮询与错误边界处理。

## 变更内容

**界面与交互优化**（Windows / Android / iOS）

- **实例管理文件夹页签与平切转场**：实例管理顶栏升级为一体 SVG 文件夹耳标页签（切换页签跟随方向做横向同向平切，跨实例切换跟随卡片带轴向滑动；管理内终端在切换实例时保持日志井框体稳定并仅更新日志内容）。
- **竖屏管理卡片带调整**：竖屏顶部横向实例卡片带调整为 1:1 方卡布局，未选中卡片等比缩放突出焦点，桌面侧栏展开态继续保持 3:4 卡片比例。
- **细节与性能收敛**：顶栏时钟对齐分钟边界刷新，减少空闲重绘；仅在存在远程实例时开启 15 秒在线状态轮询；修正右下角曲线缩放手柄的悬停与拖拽激活视觉层次，并统一取消类/未实现接口报错边界。

**各平台同步说明**

- **Windows**：同步上述 `1.15.1` 前端更新，完整保留 Windows 控制台、强类型 IPC、系统目录选择与 ZIP 导入导出。
- **Android**：同步上述 `1.15.1` 前端更新，完整保留 SAF 存储访问控制与既有架构，版本升为 `1.15.1`（versionCode `78`）。
- **iOS**：同步上述 `1.15.1` 前端更新并补齐弹窗与遮罩同步退场细节，完整保留 iOS 控制台及 NodeMobile 运行时，版本升为 `1.15.1`（Build `52`）。
