# SillyClient v1.14.2

> iOS 修复版 Build 46：修复新建实例安装目录选择与权限回填链路。Windows / Android 本版不更新，不提供安装包。

## iOS 修复

- Files 文件夹选择结果现在通过 `NSFileCoordinator` 只读协调，并使用 provider 返回的访问 URL 检查目录，避免未协调的 POSIX 检查导致选择后不回填。
- 保留原始 picker 授权并写入 security-scoped bookmark；创建实例时恢复同一目录，不静默回退到 Documents。
- 只把明确的 `PICKER_CANCELLED` 视为用户取消；Files provider 的其他错误会显示具体阶段与系统错误码。
- 保持 `root/exact` 路径模式及新建、持久化、启动路径一致；未改动 Android、Windows 后端。

## 验证

- Build 46，版本 `1.14.2`，arm64 未签名 IPA；安装前需使用现有侧载工具签名。
