# SillyClient v1.14.2

> iOS：紧急修复新建实例安装目录选择与路径回填链路，确保 iOS 权限与目录持久化 100% 畅通（Build 40）。Windows / Android：本版无更新，继续使用 v1.14.1。

## 变更内容

### iOS

- **新建实例安装目录选择与路径回填修复（核心修复）**：
  - **向导 iOS 身份透传**：向导组件完整注入 `isIOS` 状态标识，恢复原生系统文件选择器操作引导（“进入目标文件夹后点击右上角「打开」确认”）。
  - **精确与根目录模式智能判定**：完整支持 `root/exact` 目录模式，Documents 实例根预填和用户选择的新目录均按父目录安全建立实例子文件夹，手动编辑路径自动切换为精确路径，消除路径冲突。
  - **屏蔽不支持的 ZIP 运行时入口**：新建向导精准隐藏 iOS 平台不支持的本地运行时 ZIP 安装按钮，引导用户通过「实例管理 ➔ 存储路径」进行安全数据迁移。
  - **全链路一致性保障**：目录选择回填、实例创建、持久化注册与启动调用全链路 100% 路径同构，彻底根治真机创建实例时的路径无法确认或选择后不回填问题。
- **版本号与 Build 递增**：
  - 原生工程与 `Info.plist` 版本号升至 `1.14.2`，Build 号递增至 `40`。
  - 自动化测试与 CI 流水线对齐：72 项前端单测、32 项 iOS 运行时与契约测试、7 大套件云端探针全量 PASS，macOS-15 官方构建 Run `42871644356`。

### Windows

- 本版无更新，继续使用 v1.14.1。
- 坚守前后端强类型 IPC 契约与纯净门面，88 项测试网 100% 绿灯。
- 实例管理 Storage 页签原生支持流式导出 ZIP 与导入预检。
- 覆盖安装，存量实例与配置 100% 安全保留。

### Android

- 本版无更新，继续使用 v1.14.1（versionCode 76）。
- WebView 硬件管线优化，彻底消除 120Hz/144Hz 高刷屏画面撕裂与频闪。
- 新增「酒馆性能优化」专属设置拨杆，实例运行时间统计与持久化接管。
- 系统级 SAF 存储守护与沉浸式变色龙渲染引擎（全时/单次取色模式与点击光效联动）。
