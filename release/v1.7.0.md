# SillyClient 1.7.0

本次更新重新整理了控制台的设置与实例管理体验，补充远程实例认证，并统一收敛了 Android、Windows 与网页演示中的交互动效。

## 更新内容

- APP 设置改为顶部分类切换布局，减少区块与分割线，并将重新演示、发布页和维护操作放入更清晰的功能层级
- 更新首次使用引导，使步骤顺序、局部展开说明和配图与当前实例创建、控制台、背景及设置界面一致
- 调整卡片、按钮、列表和二级菜单动效，取消全局 hover 位移；实例二级菜单仅保留文字高光
- 改善新建实例的版本选择：列表从当前选择项向上展开，版本由高到低排列，本地 ZIP 导入移动到版本区域
- 修复 Android 与 Windows 上实例设置面板无法打开、遮罩残留以及关闭后立即重新打开的问题
- 远程实例新增 HTTP Basic Auth 配置；Android 使用 Keystore 与 AES/GCM，Windows 使用 Electron `safeStorage`，密码不会写入 URL、日志或前端 `localStorage`
- Android 在新建实例后首次进入 SillyTavern 时显示一次顶部滑动返回提示
- 修复 Windows 应用图标与 AppUserModelId，并继续使用应用内窗口或系统浏览器两种内容打开方式
- Android、Windows 与网页演示继续使用同一套 React 控制台构建，网页产品图同步更新为当前界面

## 下载

- `SillyClient-Android-v1.7.0.apk`
- `SillyClient-Windows-v1.7.0.exe`

Android 支持 Android 8.0 及以上的 arm64 设备。Windows 支持 Windows 10 / 11 x64。
