# SillyClient v1.7.0

> Windows：修复应用图标，远程实例密码使用 safeStorage。Android：远程实例密码使用 Keystore，新建实例后提示一次顶部滑动返回（versionCode 11）。iOS：本版没有安装包。两端共用设置面板修复和同一套控制台动效。

## 变更内容

**界面**（Windows / Android）

- APP 设置改为顶部分类切换。重新演示、发布页和维护操作放进更清晰的功能层级。
- 更新首次使用引导，使步骤顺序、局部展开说明和配图与当前界面一致。
- 调整卡片、按钮、列表和二级菜单动效，取消全局 hover 位移。实例二级菜单仅保留文字高光。
- 新建实例的版本列表从当前选择项向上展开，版本由高到低排列。本地 ZIP 导入移动到版本区域。
- 修复实例设置面板无法打开、遮罩残留，以及关闭后立即重新打开的问题。
- 两端与网页演示继续使用同一套 React 控制台构建。

**Windows**

- 远程实例的 HTTP Basic Auth 密码使用 Electron `safeStorage`。密码不会写入 URL、日志或前端 `localStorage`。
- 修复应用图标与 AppUserModelId。内容仍可在应用内窗口或系统浏览器中打开。

**Android**

- 远程实例的 HTTP Basic Auth 密码使用 Keystore 与 AES/GCM。密码不会写入 URL、日志或前端 `localStorage`。
- 新建实例后首次进入 SillyTavern 时显示一次顶部滑动返回提示。
- 版本 1.7.0（versionCode 11）。

**iOS**

- 本版没有安装包。
