# SillyClient 1.6.0

本次更新完善了首次使用流程与 Windows 端实例安装，并提高了版本获取在不同网络环境下的可用性。

## 更新内容

- 新增首次使用引导，依次介绍实例创建、控制台、背景主题与 APP 设置；完成后仍可从设置中重新查看
- 引导窗口会随当前内容自动调整尺寸并保持居中，主步骤、展开页与关闭操作使用连续转场
- Windows 可选择在应用内窗口或系统浏览器中打开 SillyTavern
- 创建本地实例时自动获取当前正式版本，并持续显示下载、解压、依赖安装与可运行性检查状态
- GitHub 版本接口不可用时自动切换只读元数据来源，源码下载继续使用官方仓库地址与镜像降级链
- Windows 安装失败时清理未完成目录和临时压缩包，避免残留实例被误识别
- 数字配置项改用与 Android 一致的文本输入样式，不再显示 Windows 原生步进按钮
- Android、Windows 与网页演示继续使用同一套 React 控制台构建

## 下载

- `SillyClient-Android-v1.6.0.apk`
- `SillyClient-Windows-v1.6.0.exe`

Android 支持 Android 8.0 及以上的 arm64 设备。Windows 支持 Windows 10 / 11 x64。
