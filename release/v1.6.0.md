# SillyClient v1.6.0

> Windows：可选应用内窗口或系统浏览器打开酒馆，安装失败会清理残留。Android：同步同一套首次引导与控制台（versionCode 10）。iOS：本版没有安装包。版本列表在 GitHub 接口不可用时会切换备用源。

## 变更内容

**界面**（Windows / Android）

- 新增首次使用引导，依次介绍实例创建、控制台、背景主题与 APP 设置。完成后仍可从设置中重新查看。
- 引导窗口会随当前内容自动调整尺寸并保持居中，主步骤、展开页与关闭操作使用连续转场。
- 创建本地实例时自动获取当前正式版本，并持续显示下载、解压、依赖安装与可运行性检查状态。
- GitHub 版本接口不可用时自动切换只读元数据来源。源码下载继续使用官方仓库地址与镜像降级链。
- 数字配置项改用文本输入，不再显示 Windows 原生步进按钮。
- 两端与网页演示使用同一套 React 控制台构建。

**Windows**

- 可选择在应用内窗口或系统浏览器中打开 SillyTavern。
- 安装失败时清理未完成目录和临时压缩包，避免残留实例被误识别。

**Android**

- 版本 1.6.0（versionCode 10）。

**iOS**

- 本版没有安装包。
