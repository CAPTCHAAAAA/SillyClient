# SillyClient v1.14.3

> iOS 紧急修复版（`1.14.3` / Build `48`）：全面修复 Files / iCloud 文件夹与文件选择全链路故障（手势下滑关闭选择器后后续选择锁死、外置目录 Bookmark 易失/陈旧拒用、源目录/ZIP/封面/文本选择缺少文件协调及前端吞咽系统报错）。本版为紧急补丁，仅更新 iOS，连续跳过 Windows 与 Android（继续使用 `v1.14.1`，后续统一整合）。

## iOS 修复

- **选择器关闭后不再卡死**：为 `UIDocumentPickerViewController` 补充 `UIAdaptivePresentationControllerDelegate` 与 `presentationControllerDidDismiss` 处理；手势下滑或点击外部取消时正确清空等待中的回调并返回 `PICKER_CANCELLED`，同时补齐退场过渡重试与孤立回调回收，避免后续所有目录/文件选择持续报选择器被占用。
- **外置目录授权持久化与 Stale 自动恢复**：
  - 改为标准 `bookmarkData(options: [])` 与 `.withoutChanges` 只读协调，并将外部目录 bookmark 生成移入 `select` 的协调读取作用域内；
  - 遇到 `stale == true` 的书签时，只要安全作用域启动成功且协调后目录身份校验一致，就自动刷新持久化 bookmark 并继续使用（权限已丢失或目录被替换仍拒绝）；
  - 外置目录读写能力探针改为在 `NSFileCoordinator(writingItemAt:options:.forReplacing)` 协调内执行，失败时附带具体系统域与错误码。
- **全入口文件协调、队列淘汰与陈旧设置清理**：
  - 源目录、导入 ZIP、封面图片与文本读取均补齐 `NSFileCoordinator` `.withoutChanges` 读取协调与主队列回调；
  - 外置源目录安全作用域队列支持 FIFO 淘汰（上限 8 个），不再达到上限后永久拒选新目录；无扩展名封面图回退 `.png`；
  - `getAppSettings()` 启动读取时自动校验 `configuredInstancesRoot`，失效路径会自动清理不再误回填。
- **前端取消判定与中文报错诊断**：
  - storage 迁移弹窗改用 `shouldShowDirectoryPickerError(error, isIOS)`，不再把包含 `cancel` 的 Files provider 错误误判为取消并静默忽略；
  - 首页安装目录选择与封面选择统一接入中文错误提示，涵盖 iCloud 未下载、`ENOTSUP`/provider 不支持局部运行时、bookmark 失效与系统容器目录拒绝等场景。
- **未改动 Windows、Android**。
