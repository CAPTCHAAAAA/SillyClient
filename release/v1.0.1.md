# SillyClient v1.0.1

> Windows：本版没有安装包。Android：首个正式版，在手机上本地运行 SillyTavern，不需要 Termux。iOS：本版没有安装包。

## 变更内容

**Android**

- 多实例创建和切换，支持本地实例和远程连接。版本列表从 GitHub Release 拉取。
- 卡片轮播支持拖拽、滑动、方向键和圆点。封面可通过系统图片选择器更换。支持重命名、管理和卸载。
- 内置 Node.js。本地实例会下载酒馆、写入配置并启动。远程实例用原生请求检查是否在线。
- 可配置端口、局域网监听、IPv4 / IPv6、心跳间隔和 HTTP Keep-Alive。配置写入酒馆的 `config.yaml`。
- 终端显示实时日志，可输入命令，可调节字号和面板大小，也可刷新酒馆页面。
- 可导出和导入实例配置 JSON。可扫描孤立目录、孤立封面、临时文件和 WebView 缓存。卸载会删除安装目录和封面。
- 支持动态背景、自定义壁纸、明暗主题和安全区避让。
- 支持下拉刷新和实例搜索。
- 修复更换插图闪退和第二次更换失败，修复版本菜单超出屏幕，修复卸载后不删除原生文件。
- 移除未使用的 npm 依赖和界面组件，清理死代码。

**Windows**

- 本版没有安装包。

**iOS**

- 本版没有安装包。

## 下载与校验

- Windows：本版没有安装包。
- Android：`SillyClient-v1.0.1-arm64-v8a.apk`。Android 7.0（API 24）及以上，arm64-v8a。首次启动约需 200 MB。
- iOS：本版没有安装包。
