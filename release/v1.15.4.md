# SillyClient v1.15.4

> 全平台扩展安装、预制插件下载与交互动效修复更新（统一版本 `1.15.4`：Android versionCode `80`、Windows `1.15.4`、iOS Build `55`）：解决三端酒馆内安装/更新扩展报错 `spawn git ENOENT` 与失效镜像导致的预制插件下载失败，修复 iOS 背景图列表空白与缩略图失效问题，并统一全站悬停过渡节拍。

## 变更内容

### iOS（Build `55`）

- **修复背景图列表空白与缩略图失效**：为未启用 ICU 的 NodeMobile 运行时补齐纯 JS `Intl.Collator` / `DateTimeFormat` / `NumberFormat` 兜底，解决 `POST /api/backgrounds/all` 抛出 `ReferenceError: Intl is not defined` 导致初始背景图与新导入背景图全部不显示、无法选择的问题；无 WebAssembly 时将 `src/jimp.js` 切换为内置纯 JS 解码器（附带 `16MP` / `128MB` 内存上限保护，避免 8K 壁纸解码触发内存峰值闪退）。
- **加固预制拓展插件安装与酒馆内 Git 桥接**：移除失效的 `ghfast.top` / `ghproxy.net`，启用多节点镜像池与粘性优先记源、补齐 `Accept-Encoding: identity`、在镜像循环内完成 SHA-256 校验与失败清场、贯通下载进度回传并补全清单及 `.git` 元数据；新增覆盖主线程与 `Worker`（ESM / CJS）的纯 JS Git 桥接与更新孤儿文件清理。

### Android（versionCode `80`）

- **内置离线纯 JS Git 桥接兜底**：随包分发零外部依赖的 `isomorphic-git` 桥接组件，通过 `NODE_OPTIONS` 预加载与运行时回退同时覆盖 ESM、CJS 与 `Worker` 线程，解决旧版 SillyTavern（`<= 1.16.x`）缺少本地 `isomorphic-git` 导致的 `Error: spawn git ENOENT`；修正预制扩展提交哈希，切换至可用 Git Smart HTTP 镜像池（`gh-proxy.com`、`gh-proxy.org`、`v6.gh-proxy.org`、`ghproxy.vip`），并在 `pull` / `checkout` 更新时依据 `.git/sillyclient-tree.json` 自动清理上游已删除的旧文件与空目录。
- **修复预制拓展插件下载与进度心跳**：移除失效镜像，启用 5 节点 ZIP 镜像池并记忆批次最快源；增加 `Accept-Encoding: identity`、直连快速超时（8s 连接 / 15s 读取），并将大小与 SHA-256 校验移入镜像循环内（错包自动删档切换下一镜像）；持续节流上报下载进度防止大包触发超时，兼容 `./` 与数组形式 `js`/`css` 清单入口。

### Windows（`1.15.4`）

- **内置离线纯 JS Git 桥接兜底**：随安装包分发 `resources/git-bridge/` 并在启动服务时自动注入 `NODE_OPTIONS` 预加载；系统未安装 `git.exe` 时自动以纯 JS 桥接处理酒馆内扩展克隆、检测与更新（覆盖 ESM、CJS 与 `Worker`）；已安装 `git.exe` 时自动识别预制扩展目录，避免直接 `git pull` 报错。
- **升级下载镜像与预制拓展安装**：移除失效镜像并统一升级为 5 节点镜像池（含批次最快源记忆）；`downloadFile` 增加 `Accept-Encoding: identity` 与首字节响应头超时（避免直连 GitHub 长时间卡死且不影响大包流式传输）；将大小与 SHA-256 校验移入镜像循环，兼容 `./` 清单路径并补写 `.git` 元数据与 `.git/sillyclient-tree.json`。

### 跨端通用前端（Windows / Android / iOS / Web）

- **统一全站悬停过渡节拍与修复硬切**：新增 `--motion-hover: 500ms` 令牌并统一按钮、开关选项、分页点与设置项悬停过渡（`prefers-reduced-motion` 下自动归零）；修复顶部控制岛按钮与壁纸导入按钮悬停 0ms 硬切及多处残余过渡类冲突，保持按压即时响应与卡片 3D 动效不变。
