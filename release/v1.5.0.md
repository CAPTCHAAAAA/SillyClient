# SillyClient v1.5.0

> Windows：控制台改为 cmd.exe 提示，安装版直接使用内置运行时。Android：补齐创建、删除和状态回报（versionCode 9）。iOS：本版没有安装包。两端共用创建事务和卡片修复。

## 变更内容

**创建与状态**（Windows / Android）

- 删除实例前增加两阶段确认，并与动态、深色、浅色主题保持一致。
- 创建本地实例时展示下载、解压、依赖安装和可运行性检查进度。
- 只有 SillyTavern 确认可访问后，实例才会写入列表并显示创建成功。
- 安装失败会清理未完成目录，避免残留实例被误识别。
- 修复实例卡片、菜单与横向轮播的裁切和异常阴影。
- 修复应用重启后实例运行状态可能失真的问题。
- 修复关闭酒馆后原生层仍报告 ready 的问题。
- 增加实例 ID 路径校验与 zip 解压越界防护。

**Windows**

- 控制台改为真实的 `cmd.exe` 提示，不再显示 Termux 文案。
- 内置运行时按生产资源路径加载，安装版可直接运行。

**Android**

- 版本 1.5.0（versionCode 9）。

**iOS**

- 本版没有安装包。
