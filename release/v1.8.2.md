# SillyClient v1.8.2

> Windows：选择「应用内窗口」时不再误开系统浏览器。Android：酒馆内导出改为调用系统保存。iOS：本版没有安装包。两端共用更新检查和卡片视觉修正。

## 变更内容

**界面**（Windows / Android）

- 酒馆顶部返回提示改为直接显示在状态栏内，并随应用版本更新重新提示。
- 应用更新检查改为前端实现。打开后自动检查，发现新版本会显示更新提示。设置中仍保留手动检查入口。
- 实例卡片展开、菜单弹出与按钮视觉统一，修正卡片圆角和阴影。
- 减少状态栏取色、动画和前端重复渲染带来的资源占用。

**Windows**

- 修复设置选择「应用内窗口」后仍会打开系统浏览器的问题。只有明确选择系统浏览器时才会外部打开。

**Android**

- 修复进入 SillyTavern 后导出文件无法触发系统保存的问题。聊天记录、角色卡、世界书等导出调用系统文件选择器。
- 导出先写入缓存临时文件，完整成功后再提交到用户选择的位置。失败或取消不会删除用户已有的文件。

**iOS**

- 本版没有安装包。
