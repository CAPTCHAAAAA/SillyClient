# SillyClient v1.15.3

> 全平台稳定性与诊断修复更新（统一版本 `1.15.3`：Android versionCode `79`、Windows `1.15.3`、iOS Build `54`）：重点解决 iOS 重启/重装后已有实例因目录身份变动被锁死的问题，并全面修复 Windows 启动报错信息丢失与重命名占用失败、Android 冷启动/创建超时及卸载目录残留、以及网页预览端诊断拦截问题。

## 变更内容

### iOS（Build `54`）

- **修复实例目录身份误判锁死（`#15` / `#16`）**：兼容 iOS 设备重启或文件系统重挂载后的卷设备号（`st_dev`）变化；引入持久化所有权令牌（`ownershipToken`）与自愈重绑定机制，支持经由受控回执校验的重装/容器恢复实例自动恢复可用与正常卸载，同时继续拦截未经授权的外部目录替换以保护用户数据。

### Windows（`1.15.3`）

- **修复启动失败信息丢失与早退误报（`#9`）**：启动失败时将真实错误信息随结果直接返回前端，不再因异步事件时序竞争而退回通用兜底提示；Node.js 进程在就绪前异常退出时立即返回退出码与错误摘要，不再误报为 180 秒启动超时。
- **修复重命名目录占用失败（`#12`）**：实例重命名纳入操作串行队列，执行前检测是否仍有终端或后台子进程占用目标目录；遇到短暂的文件句柄占用（`EPERM` / `EBUSY` / `EACCES`）时自动退避重试，仍无法重命名时给出明确占用提示，并同步刷新目录大小缓存。

### Android（versionCode `79`）

- **放宽冷启动就绪检测并支持活动续期（`#14` / `#17`）**：单次本地就绪探活超时从 `300ms` 提升至 `2000ms`，基础冷启动等待由 `60s` 提升至 `120s`，当服务进程持续有输出时按 `30s` 宽限续期至最高 `180s`，并在超时时提供脱敏后的进程状态诊断。
- **加固实例删除残留兜底（`#13`）**：删除前停止服务等待放宽至 `5s`；保留「目录未删净不注销实例」的安全不变量，在系统清理命令返回成功后若检测到残留项，自动执行不跟随符号链接的有限次兜底清理，仍无法清空时给出不含用户路径的残留诊断提示。

### 跨端通用前端（Windows / Android / iOS / Web）

- **创建与安装超时改为活跃心跳续期（`#11`）**：移除固定的 10 分钟墙钟超时限制，改为基于后台进度与日志输出的活跃心跳续期（5 分钟无进展空闲超时、25 分钟总时长上限），避免网络较慢环境下正常下载或安装依赖被提前打断。
- **优化诊断聚合与网页预览隔离（`#14` / `#17` / `#18` / `#19` / `#20`）**：报错脱敏保留常见产品关键词以避免同源问题被拆分为多条记录；为网页预览端的实例启动、连接、返回与停止操作补齐平台提示兜底，并将默认诊断上报限定在原生客户端生产环境，防止网页预览与本地开发产生噪音上报。
