# SillyClient v1.1.0

> Windows：本版没有安装包。Android：修复 npm 安装和服务器启动，菜单改为系统字体和液态玻璃。iOS：本版没有安装包。

## 变更内容

**Android**

- 把 npm 打进 APK。修复压缩包路径分隔符和 npm 缓存路径。兼容 npm 11，使用淘宝镜像，失败自动重试 3 次。
- 启动前结束旧进程并释放端口。进程退出时立刻报错，不再一直停在等待。
- Node 内存上限设为 2048 MB。就绪检测超时从 120 秒改为 180 秒。
- 去掉 Google Fonts，改用系统字体。二级和三级菜单统一液态玻璃。动态、黑夜、白天分别使用对应底色。
- 日志符号改为 `[OK]`、`[ERR]`、`[WARN]`。去掉多余的小字注释。
- 技术栈为 Capacitor 7、React、TanStack Router、Kotlin、Node.js 24、npm 11。酒馆在本地运行。

**Windows**

- 本版没有安装包。

**iOS**

- 本版没有安装包。

## 下载与校验

- Windows：本版没有安装包。
- Android：`SillyClient-v1.1.0-arm64-v8a.apk`。Android 10 及以上（API 29），arm64-v8a，可用内存 3 GB 以上。
- iOS：本版没有安装包。
