# SillyClient 1.9.2

## 核心变化

### 1. 前端架构全面解耦与操作体验升级
- **控制台解耦与模块化**：彻底重构原本庞大的单体控制台，将实例管理、新建向导、系统设置、个性化壁纸、新手引导与确认交互完全拆解为高内聚的独立模态组件。
- **实例卡片双击内联编辑**：支持双击实例标题直接就地重命名，Enter 保存，Esc 取消，操作更加轻快。
- **后台活动胶囊（Activity Capsule）**：实例启动后控制台自动轻量收缩为活动胶囊挂载后台，支持一键在前端控制面板与酒馆运行页面之间无感穿梭切换。
- **全局浮层与弹窗栈治理（useLayerStack）**：统一桌面端 ESC 键与移动端物理返回键行为，遵循严格 LIFO 关闭顺序，彻底消除弹窗层级穿透与遮罩残留。
- **全站精细化视觉优化**：建立语义化分层 Z-Index 标尺；消除输入框焦点状态下的荧光绿与外发光阴影；向导与背景弹窗支持昼夜平滑高度跟随溶变；修复启动控制台绝对居中双重 translate 抖动缺陷。

### 2. 官方新增 iOS 平台支持（SillyClient for iOS）
- **免越狱与标准签名支持**：支持 iOS 14.0+，提供开箱即用的标准 `.ipa` 安装包，兼容万能签、爱思助手、AltStore、TrollStore、SideStore 或自签名证书直接安装部署。
- **完全离线 NodeMobile 进程内服务**：内置 NodeMobile (Node.js v18 LTS) 进程内运行时，内置 SillyTavern 纯 JS 完整生产服务，无需依赖网络或外部环境即可离线启动酒馆。
- **硬件与系统级深度适配**：
  - 变色龙双引擎智能顶部取色熔接（ChameleonEngine），实现状态栏与酒馆界面的 100% 满色无缝熔接。
  - 灵动岛与状态栏硬件避让（IslandHardwareRadar），有效保障界面不被刘海遮挡。
  - 底部满版通底（Full Bleed）设计，Home Indicator 智能淡出避让与原生软键盘弹出自然避让。
- **系统多媒体与专属终端**：
  - 声明录音与麦克风权限支持（STT 语音输入与 WebRTC 语音对讲）。
  - iOS 专属沙盒控制台终端，支持状态诊断与 `gc` 垃圾回收命令。

### 3. 多端全面同步
- Android 与 Windows 客户端全量同步升级搭载最新现代前端架构与视觉优化，多端保持一致的产品体验。
