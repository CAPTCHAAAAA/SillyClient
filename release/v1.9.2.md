# SillyClient v1.9.2

> Windows：同步拆开后的新前端。Android：锁定设备最高刷新率，酒馆在前台时让控制台休眠。iOS：本版开始提供 IPA，iOS 14.0 及以上。三端共用拆开后的控制台。

## 变更内容

**界面**（Windows / Android / iOS）

- 控制台拆成实例管理、创建实例、APP 设置、壁纸、新手引导和确认框。
- 实例卡片支持双击标题重命名，回车保存，Esc 取消。
- 实例启动后，控制台可以收成后台活动胶囊，在控制台和正在运行的酒馆之间切换。
- 桌面 Esc 和手机返回键走同一层浮层栈，按后进先出关闭，避免弹窗穿透和遮罩残留。
- 去掉输入框聚焦时的绿色外发光。向导和背景弹窗的高度可以随昼夜主题过渡。

**Windows**

- 同步上述前端。

**Android**

- 锁定设备支持的最高刷新率，包括 120Hz 和 90Hz。
- 酒馆在前台时，底下的控制台休眠，避免两个 WebView 抢资源。
- 不再向酒馆页面注入样式。滚动锚定和新消息贴底保持酒馆原样。
- 顶部取色优先读 DOM 和主题变量，滑动过程中不再截屏。手势退出后再返回会重新取色。
- 顶栏轻触光波保留。点击和滑动分开处理。

**iOS**

- 新增 iOS 支持。iOS 14.0 及以上，提供 IPA，可用自签名或常见侧载方式安装。
- 内置进程内 Node 运行时和酒馆生产服务，可离线运行。
- 适配状态栏、灵动岛、底部安全区和键盘避让。
- 支持麦克风输入。沙盒控制台可以查看状态，也可以执行 gc。
