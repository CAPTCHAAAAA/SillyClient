# SillyClient 1.9.1

## 更新内容

### 平台修复

- 修复 Android 与 Windows 导入壁纸图片后界面卡死的问题。

### iOS 平台支持

- 新增 iOS 平台支持（基于内置 NodeMobile 运行时，免越狱纯解释器模式，不依赖 JIT）。
- 适配 iOS 顶栏变色龙自适应色彩熔接与系统状态栏、灵动岛硬件区域避让。
- 适配底栏无缝满版延展（Full Bleed）与输入法软键盘弹出避让。
- 支持系统原生文件选择器（`UIDocumentPickerViewController`）与分享导出面板（`UIActivityViewController`）。
- 支持酒馆麦克风语音输入授权与后台音频保活。

- Android 8.0 及以上 arm64 设备
- Windows 10 / 11 x64
- iOS 14.0 及以上 arm64 设备（支持万能签、轻松签、巨魔商店、爱思助手等签名安装）
