# SillyClient 1.9.0

## 更新内容

### 控制岛与玻璃材质

- 顶部控制岛重新调整玻璃层次，加入轻微边缘高光、背景模糊和更自然的外部阴影，减少厚重描边带来的割裂感。
- 左右功能按钮与中间主题控件统一为轻微内凹的光学反差样式，在保留清晰点击区域的同时降低视觉重量。
- 竖屏下控制岛会按手机宽度自动缩放；横屏和桌面端设置最大宽度并保持居中，不再铺满屏幕。
- 弹出菜单补充独立阴影和层级，避免与控制岛本体混成一片。

### 壁纸与主题预设

- 设置壁纸后，标题仍保持清晰可见；白天模式使用浅色半透明遮罩，黑夜模式使用深色半透明遮罩。
- 新增壁纸磨砂强度调节，并优化滑槽、拨杆和面板排版，使控制项与现有界面风格一致。
- 动态、白天、黑夜分别使用独立的材质草稿、保存槽和历史记录，切换模式不会再串用另一套参数。
- 材质控制台支持显示保存时间、查看历史保存，并可导出当前模式或全部模式的预设。
- 内置三套初始材质参数受到保护；用户主动调整前不会被旧草稿或其他主题模式覆盖。
- 改善黑白主题切换的颜色过渡，并缩小、柔化屏幕边缘的渐进虚化范围。

### 实例卡片

- 修复实例详情展开时遮罩与内容一起参与弹性位移、导致卡片局部遮罩缺失的问题。
- 展开与收回改为连续的淡入淡出和位移过渡，减少突然弹出、快速收回和边缘被遮挡的感觉。
- 统一 Android 与 Windows 的实例卡片材质参数，修复移动端雾面强度、饱和度和圆角显示不一致。
- 保留现有卡片结构与操作方式，只更新材质、遮罩层和过渡表现。

### 创建实例与 SC Bordeaux

- 创建本地实例时新增“主题预设”选项，可选择内置 `SC Bordeaux`。
- 启用后会在实例安装完成时自动写入主题文件、配套 8K 壁纸和对应设置，无需再手动导入。
- 主题预设使用一次性应用标记，后续启动不会反复覆盖用户已经修改的外观。
- 如果实例安装或首次启动失败，未完成的主题预设写入会自动回滚，避免留下不完整配置。
- 默认版本入口由“稳定版”调整为“内置版”，对应应用自带的最新本地版本。

### 新手引导与稳定性

- 新手引导更新为五步流程，覆盖新建实例、主题预设、实例卡片、控制台以及背景与 APP 设置。
- 引导配图替换为当前界面的实际截图，并改善步骤切换速度、内容淡入和容器尺寸过渡。
- 材质配置存储升级到版本 3，在隔离三套主题数据的同时保留用户已有的显式保存记录和历史。
- Windows 升级压缩包处理依赖，消除生产依赖安全审计中的已知高危项。

## 升级说明

- 已有实例不会自动套用 `SC Bordeaux`；该选项只在用户创建本地实例时明确启用后生效。
- 已保存的材质预设和历史记录会继续保留。旧版草稿会迁移到对应主题模式，不会覆盖三套内置初始参数。
