# SillyClient v1.9.0

> Windows：升级压缩包处理依赖，去掉已知高危项。Android：与 Windows 共用控制岛、壁纸材质、实例卡片和 SC Bordeaux。iOS：本版没有安装包。已有实例不会自动套用该预设。

## 变更内容

**界面**（Windows / Android）

- 顶部控制岛改为边界清晰的玻璃质感。左右功能按钮与中间主题控件保持统一的内凹风格。弹出菜单与控制岛、背景分层清楚。
- 竖屏下控制岛按设备宽度自适应。横屏和桌面端保持限宽居中。
- 壁纸场景下标题保持可读。白天与黑夜分别保持合适的明暗对比。壁纸磨砂强度可调。屏幕边缘虚化更自然。
- 动态、白天、黑夜分别拥有独立的材质草稿、保存记录和历史。首次调整前，三套内置参数保持稳定。
- 材质控制台显示保存时间与历史，并支持导出当前模式或全部模式预设。
- 实例详情展开与收回保持连续过渡，卡片遮罩保持完整。两端卡片的雾面强度、饱和度和圆角一致。卡片原有结构与操作方式不变。
- 创建本地实例时可选内置 SC Bordeaux。启用后在安装完成时写入主题、配套 8K 壁纸和对应设置。只应用一次，之后不会反复覆盖用户改过的外观。安装或首次启动失败时自动回滚。
- 已有实例不会自动套用 SC Bordeaux。该选项只在创建本地实例时明确启用后生效。已保存的材质预设和历史会保留。旧版草稿迁到对应主题，不覆盖三套内置初始参数。
- 默认版本入口由「稳定版」调整为「内置版」，对应应用自带的最新本地版本。
- 新手引导改为五步，覆盖新建实例、主题预设、实例卡片、控制台，以及背景与 APP 设置。配图换成当前界面。
- 材质配置存储升级到版本 3，分开保存三套主题，同时保留已有的显式保存记录和历史。

**Windows**

- 升级压缩包处理依赖，消除生产依赖安全审计中的已知高危项。

**Android**

- 控制岛、壁纸材质、实例卡片和 SC Bordeaux 与 Windows 使用同一套界面。

**iOS**

- 本版没有安装包。
