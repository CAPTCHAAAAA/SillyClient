# SillyClient 1.9.0

## 更新内容

### 控制岛与玻璃材质

- 顶部控制岛呈现轻盈、通透且边界清晰的玻璃质感，整体空间层次更加协调。
- 左右功能按钮与中间主题控件保持统一的内凹光学风格，交互反馈清晰且克制。
- 竖屏下控制岛按设备宽度自适应；横屏和桌面端保持限宽居中。
- 弹出菜单具有明确的悬浮层级，与控制岛和背景保持清晰区分。

### 壁纸与主题预设

- 壁纸场景下标题始终清晰可读，白天与黑夜模式分别保持合适的明暗对比。
- 壁纸磨砂强度支持精细调节，滑槽、拨杆和面板排版保持统一风格。
- 动态、白天、黑夜分别拥有独立的材质草稿、保存记录和历史数据。
- 材质控制台清晰显示保存时间与历史记录，并支持导出当前模式或全部模式预设。
- 用户首次调整前，三套内置材质参数始终保持稳定。
- 明暗主题切换更加连贯，屏幕边缘虚化范围自然且克制。

### 实例卡片

- 实例详情展开与收回保持连续、轻柔的视觉过渡，卡片遮罩始终完整。
- Android 与 Windows 的实例卡片拥有一致的雾面强度、饱和度和圆角表现。
- 实例卡片原有结构与操作方式保持不变。

### 创建实例与 SC Bordeaux

- 创建本地实例时新增“主题预设”选项，可选择内置 `SC Bordeaux`。
- 启用后会在实例安装完成时自动写入主题文件、配套 8K 壁纸和对应设置，无需再手动导入。
- 主题预设使用一次性应用标记，后续启动不会反复覆盖用户已经修改的外观。
- 如果实例安装或首次启动失败，未完成的主题预设写入会自动回滚，避免留下不完整配置。
- 默认版本入口由“稳定版”调整为“内置版”，对应应用自带的最新本地版本。

### 新手引导与稳定性

- 新手引导更新为五步流程，覆盖新建实例、主题预设、实例卡片、控制台以及背景与 APP 设置。
- 引导配图替换为当前界面的实际截图，并改善步骤切换速度、内容淡入和容器尺寸过渡。
- 材质配置存储升级到版本 3，在隔离三套主题数据的同时保留用户已有的显式保存记录和历史。
- Windows 升级压缩包处理依赖，消除生产依赖安全审计中的已知高危项。

## 升级说明

- 已有实例不会自动套用 `SC Bordeaux`；该选项只在用户创建本地实例时明确启用后生效。
- 已保存的材质预设和历史记录会继续保留。旧版草稿会迁移到对应主题模式，不会覆盖三套内置初始参数。
