# SillyClient v1.8.1

> Windows：修复实例终端按钮无响应；本版热修复未更换 Windows 安装包。Android：修复酒馆内选择文件打不开系统选择器。iOS：本版没有安装包。

## 变更内容

**Windows**

- 修复左上角实例终端按钮无响应的问题，恢复原有弹出位置与实例级终端逻辑。
- 修复共享前端把 Windows 原生客户端误判为普通网页、从而拦截终端入口的问题。
- 未选择实例时点击终端会展开终端，并提示先选择实例。
- 本版热修复未更换 Windows 安装包，安装包内容与原发布文件相同。

**Android**

- 修复进入 SillyTavern 后，上传图片、导入 JSON 或其它文件选择无法打开系统文件选择器的问题。
- 为酒馆 WebView 补充文件选择回调，支持单选、多选和取消，并避免重复选择请求卡住页面。
- 修复系统返回的 `content://` 地址无法被酒馆页面读取的问题，同时继续禁止 WebView 任意访问本地 `file://`。

**iOS**

- 本版没有安装包。
