# SillyClient 1.8.1

本次更新为稳定性修复，解决 Windows 客户端实例终端入口失效的问题，并同步 Android、Windows 与网页演示版本。

## 修复内容

- 修复 Windows 客户端左上角实例终端按钮无响应的问题，恢复原有弹出位置与实例级终端逻辑
- 修复共享前端将 Windows 原生客户端误判为普通网页、从而拦截终端入口的问题
- 修复未选择实例时点击终端没有反馈的问题；现在会正常展开终端并提示先选择实例

## 下载

- `SillyClient-Android-v1.8.1.apk`
- `SillyClient-Windows-v1.8.1.exe`

Android 支持 Android 8.0 及以上的 arm64 设备。Windows 支持 Windows 10 / 11 x64。
