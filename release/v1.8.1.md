# SillyClient 1.8.1

本次为 `v1.8.1` 发布后的 Android 热修复，版本号保持不变。Windows 安装包沿用原发布文件。

## 修复内容

- 修复 Windows 客户端左上角实例终端按钮无响应的问题，恢复原有弹出位置与实例级终端逻辑
- 修复共享前端将 Windows 原生客户端误判为普通网页、从而拦截终端入口的问题
- 修复未选择实例时点击终端没有反馈的问题；现在会正常展开终端并提示先选择实例
- 修复 Android 进入 SillyTavern 后，点击上传图片、导入 JSON 或其它 `input[type=file]` 选项无法打开系统文件选择器的问题
- 为酒馆 WebView 补充 Android 文件选择回调，支持单选、多选和取消操作，并避免重复选择请求卡住页面
- 修复系统返回的 `content://` 文件地址无法被酒馆页面读取的问题，同时继续禁止 WebView 任意访问本地 `file://` 文件

## 下载

- `SillyClient-Android-v1.8.1.apk`
- `SillyClient-Windows-v1.8.1.exe`

Android 支持 Android 8.0 及以上的 arm64 设备。Windows 支持 Windows 10 / 11 x64。
本次仅更新 Android 安装包；Windows 安装包内容未变。
