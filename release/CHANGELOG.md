# 版本记录

这里只保留已经发布版本的用户可见变化。完整实现历史以 Git 提交和各版本 Release 说明为准。

## 2.0.0 - 2026-10-01

- Android 端性能全链路极致重构与高刷锁帧：
  - 彻底拔除 14 层带有遮罩的动态 `backdrop-filter` 渐进模糊层与卡片 SVG `feTurbulence` 噪点着色器滤镜，大幅减轻移动 GPU 显存带宽负担。
  - 彻底拔除滚动监听中的 Forced Reflow 强制同步重排，滚动全权交由 Chromium 合成器驱动；轮播开启 `-webkit-overflow-scrolling: touch` 与 `touch-action: pan-x`。
  - Android 12+ 在 WebView 句柄注入 `setFrameRate` 硬件锁定 120Hz 刷新率，杜绝手势松手后系统 LTPO 暴跌 60Hz；开启 `LAYER_TYPE_HARDWARE` 硬件加速并消除回弹拷贝。
  - ChameleonEngine 升级为零轮询纯事件驱动机制与 DOM 探针优先，彻底消除滑动期间 PixelCopy 导致的 GPU pipeline stall；实现首帧 0ms 缓存即时对齐；双 WebView 生命周期深度休眠管理。
- 前端 UI/UX 全新更改与视觉美学升级：
  - 全面恢复经典红色感叹号展开模式（`InfoBadgeButton` + `motion-accordion`）：拔除平铺机制卡片，接入方式、私有凭据（`secrets.json`）与数据预检详情统一折叠，常态下界面回归极简高级质感。
  - 无边框 Apple 流体果冻弹簧指示器：拔除胶囊外框，基于物理弹簧算法与舒适热区小圆点实现丝滑的流体过冲延展与自然吸附。
  - 卡片架构解耦与同位驻留优雅过渡：停止态与运行态卡片彻底拆分解耦，调度 `cubic-bezier(0.22, 1, 0.36, 1)` 白天黑夜级优雅溶变；内联就地重命名，消除 hover 抖动与抢占抽搐。
  - 向导子模式三态级动效：复制迁移与原地接管之间同位驻留 DOM、微位移升降与高斯虚化溶变，容器高度由 `ResizeObserver` 平滑自适应伸缩，动效层级与主三态完全对齐。
- 重磅新增跨平台“数据迁移”与实用导入能力：
  - **复制迁移**：一键将已有 SillyTavern 完整数据（聊天、角色、预设、世界书、插件）拷贝迁入独立受管存储沙盒，原文件完整保留互不干扰，自由指定目标路径。
  - **原地接管**：直接关联并复用原物理目录，零额外磁盘空间占用；特别引入“卸载防删保护机制”，客户端移除实例时绝对不误删用户原物理文件。
  - **私有凭据脱敏**：默认脱敏排除 `secrets.json`，用户可自主开启随同迁移 API Key 与认证信息。
  - **全链路原生导入**：新增跨端原生 `TarvenEnv.readTextFile` 接口（Android SAF / Windows Native Dialog），彻底修复实例备份 JSON 导入无响应缺陷；优化 `pickZipFile` 格式兼容，支持大文件后台异步解压拷贝与单根包裹自动压平。

## 1.9.2 - 2026-09-25

- 前端架构全面重构与操作内联化：
  - 解耦拆分控制台逻辑，弹窗组件（实例管理、创建实例、APP 设置、壁纸定制、新手引导）独立模块化拆解。
  - 实例卡片支持双击标题原地内联编辑名称，回车即时保存。
  - 启动控制台新增最小化后台活动胶囊（Activity Capsule），支持在管理控制台与后台运行中的酒馆实例间丝滑切换。
  - 引入统一全局浮层栈治理（`useLayerStack`），适配桌面 ESC 快捷键与移动端物理返回键，杜绝弹窗穿透与遮罩残留。
  - 建立语义化分层 Z-Index 标尺体系，消除输入框 focus 绿色/外发光阴影轮廓，向导与背景弹窗实现昼夜平滑高度跟随溶变。
- 新增 iOS 平台官方支持：
  - 支持 iOS 14.0+，提供标准免越狱 IPA 安装包（支持万能签、爱思助手、AltStore、TrollStore、SideStore 等签名工具安装）。
  - 内置 NodeMobile 进程内运行时环境与 SillyTavern 官方完整纯 JS 生产服务，支持完全离线运行。
  - 深度原生适配：变色龙双引擎智能顶部取色熔接、灵动岛与状态栏硬件避让、底部无缝满版通底（Full Bleed）与 Home Indicator 避让。
  - 支持麦克风录音与语音输入（STT / WebRTC），提供专属 iOS 沙盒控制台与内存垃圾回收（gc）交互命令。
- Android 原生 WebView 极致流畅重构与变色龙体验优化：
  - 申请 120Hz/90Hz 屏幕高刷新率，彻底消除 60Hz 帧率墙限制；
  - 消除双 WebView 资源争抢，酒馆处于前台时底座控制台深度休眠；
  - 杜绝侵入式 DOM 样式注入，完全保障 SillyTavern 原生滚动锚定与新消息触底，彻底根治消息回弹问题；
  - 变色龙双引擎（DOM 探针优先 + 零 GPU 挂起），修复手势退出后再返回自动取色，保持原汁原味轻触光波反馈。
- Windows 客户端同步搭载解耦重构的现代化新前端，多端交互体验保持一致。
