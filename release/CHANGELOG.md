# 版本记录

这里只保留已经发布版本的用户可见变化。完整实现历史以 Git 提交和各版本 Release 说明为准。

## 1.11.0 - 2026-10-08

- 跨平台 ZIP 导入与数据迁移强化：
  - 自动识别并重置从 Android 等移动端备份迁移时残留的无效容器依赖锁（`package-lock.json`）与移动端标记文件（`.sillyclient-dependencies-pending`、`.sillyclient-prebuilt-lib`），防止跨平台依赖解析陷入死循环。
- Windows 原生依赖安装与日志体验：
  - 增加长流程 10 秒定时心跳日志（`依赖安装中（已耗时 XXs，请耐心等待）...`），并在向导进度提示中明确标注首次安装需 1~3 分钟。
  - 智能分级 npm 输出日志，将第三方库常规警告（`npm warn`）降级为普通信息，仅 `npm ERR!` 标为错误，杜绝常规提示被误判为启动故障。
- iOS 实体机运行时根路径规范化修复：
  - 规范化处理 Darwin 底层 `/var` 到 `/private/var` 的软链接等价性校验，彻底修复 iOS 真机在创建实例时报 `Unsafe authorized runtime root` 的故障。

## 2.0.1 - 2026-10-01

- 核心更新公告画布 (What's New)：
  - 全屏虚化柔焦沉浸画布：更新后首次启动自动呈现全新版本主要更新全屏虚化画布；可在「APP 设置 - 维护」中随时重新打开查看。
  - 纯正轻拟物扁平与无边框设计：更新卡片与版本号标签采用低饱和轻微色差区域（4%~6% 透明度填充），拔除所有封闭线框，视觉自然柔和。
  - 三维核心更新精简梳理：直观呈现“可以使用的新功能”、“可以看到的新更新”与“可以体验到的新优化”。
- 界面动效与视觉韵律完善：
  - 设置抽屉（通用/数据/维护）与实例管理弹窗（启动/快照/存储/终端/关于）全域接入同位驻留 DOM、微位移升降与高斯模糊虚化交叉溶变动效。
  - 设置页列表项回归原生极简发丝级底部横线设计，保持克制留白与低调工具界面风格。

## 2.0.0 - 2026-10-01

- 数据迁移与文件导入：
  - 支持将旧版 SillyTavern 数据一键复制迁移至独立目录运行，新旧隔离且原文件不受影响，支持自定义目标路径。
  - 支持原地接管旧版酒馆所在目录运行，不产生重复文件副本；在客户端移除实例时仅解除登记关联，不会删除原目录中的物理文件。
  - 迁移时默认排除 `secrets.json` 防止历史密钥泄露，可按需开启随同导入。
  - 新增跨端原生文本读取接口 `TarvenEnv.readTextFile`（Android SAF / Windows 原生对话框），解决备份 JSON 导入在部分 WebView 中点击无响应的问题。
  - 增强 ZIP 导入兼容性，支持多类型 ZIP 识别、后台异步解压、单根包裹压平与基础运行底座自动补齐。
- Android 端性能与高刷重构：
  - 移除了移动端挂载的 14 层动态 `backdrop-filter` 渐进遮罩与卡片上的 SVG 实时噪点着色器滤镜，大幅降低 GPU 显存带宽与离屏渲染开销。
  - 移除了滑动监听中的强制同步重排（Forced Synchronous Layout），滚动计算交由硬件合成器直接处理。
  - Android 12+ 在 WebView 底层句柄注入 `setFrameRate` 锁定 120Hz 硬件刷新率，解决手势释放后系统动态降频到 60Hz 的掉帧问题；WebView 开启硬件加速并消除回弹拷贝。
  - 轮播容器开启硬件惯性滚动与横向手势直通，实例卡片与背景提升为独立合成层并加入排版隔离。
  - 顶部变色龙改为纯事件驱动的轻量 DOM 探针计算，停止滑动期间的截屏挂起；进入酒馆首帧直接应用缓存色消除色差过渡；酒馆前台运行时底座 WebView 自动深度休眠。
- 前端界面与动效：
  - 敏感凭据说明、运行机制与预检结果统一改为红色感叹号展开模式（`InfoBadgeButton` + `motion-accordion`），默认保持极简表单，点击后平滑展开详细说明。
  - 移除轮播指示器外层边框，改为小圆点配合物理弹簧滑块，支持触控滑动、小圆点直选与键盘左右键导航。
  - 实例卡片停止态与运行态彻底解耦为同位驻留，状态切换时平滑淡入淡出，消除 hover 抖动与位置抢占；运行中卡片直接作为控制台查看日志并支持实时命令输入。
  - 向导子模式（复制迁移 / 原地接管）切换引入同位驻留 DOM 与平滑高度自适应变形。

## 1.9.2 - 2026-09-25

- 前端架构全面重构与操作内联化：
  - 解耦拆分控制台逻辑，弹窗组件（实例管理、创建实例、APP 设置、壁纸定制、新手引导）独立模块化拆解。
  - 实例卡片支持双击标题原地内联编辑名称，回车即时保存。
  - 启动控制台新增最小化后台活动胶囊（Activity Capsule），支持在管理控制台与后台运行中的酒馆实例间丝滑切换。
  - 引入统一全局浮层栈治理（`useLayerStack`），适配桌面 ESC 快捷键与移动端物理返回键，杜绝弹窗穿透与遮罩残留。
  - 建立语义化分层 Z-Index 标尺体系，消除输入框 focus 绿色/外发光阴影轮廓，向导与背景弹窗实现昼夜平滑高度跟随溶变。
- 新增 iOS 平台官方支持：
  - 支持 iOS 14.0+，提供标准免越狱 IPA 安装包（支持万能签、爱思助手、AltStore、TrollStore、SideStore 等签名工具安装）。
  - 内置 NodeMobile 进程内运行时环境与 SillyTavern 官方完整纯 JS 生产服务，支持完全离线运行。
  - 深度原生适配：变色龙双引擎智能顶部取色熔接、灵动岛与状态栏硬件避让、底部无缝满版通底（Full Bleed）与 Home Indicator 避让。
  - 支持麦克风录音与语音输入（STT / WebRTC），提供专属 iOS 沙盒控制台与内存垃圾回收（gc）交互命令。
- Android 原生 WebView 极致流畅重构与变色龙体验优化：
  - 申请 120Hz/90Hz 屏幕高刷新率，彻底消除 60Hz 帧率墙限制；
  - 消除双 WebView 资源争抢，酒馆处于前台时底座控制台深度休眠；
  - 杜绝侵入式 DOM 样式注入，完全保障 SillyTavern 原生滚动锚定与新消息触底，彻底根治消息回弹问题；
  - 变色龙双引擎（DOM 探针优先 + 零 GPU 挂起），修复手势退出后再返回自动取色，保持原汁原味轻触光波反馈。
- Windows 客户端同步搭载解耦重构的现代化新前端，多端交互体验保持一致。
