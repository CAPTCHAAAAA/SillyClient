# SillyClient v1.13.2

> 双端更新。Android：修复进入酒馆后导入世界书、预设或角色时文件无法选中的问题。Windows：修复兜底导出私自写入用户下载目录的问题，并同步一版通用前端交互。iOS 暂无新版本。

## 变更内容

**Android**

- 原有表现：进入酒馆实例后，从页面导入世界书、预设或角色时，系统文件选择器能打开，但 `.json` 等文件呈灰色或不可点。
- 现在的表现：系统文件选择器不再按 MIME 元数据过滤这些扩展名导入项，可以正常选中文件并交给酒馆导入。
- 影响范围：v1.13.1 及更早版本的 Android 用户在导入这类文件时都可能遇到；Windows 与 iOS 不受影响。
- 同类修复：原生插件中的 JSON/文本导入和 ZIP 导入链路保持通配符兜底，不依赖厂商文件管理器上报的 MIME。
- 版本 1.13.2（versionCode 74）。覆盖安装，实例与设置保留，签名与历史版本一致。

**Windows**

- 修复：自动/兜底导出不再写 `下载\SillyClient-导出`，改为落在软件安装目录内的 `exports`。用户主动点「导出实例（ZIP）」仍弹原生保存对话框，位置完全由用户决定。
- 界面：终端与管理菜单右下角新增弧形缩放手柄，可拖动改变面板尺寸；管理菜单改为全屏居中呈现；实例终端换毛玻璃外框与下沉日志槽，点遮罩即可收起；新手引导 12 张图换成当前界面。
- 保持不变：Windows 终端文案（`Windows 控制台`、`C:\>`、`输入 Windows 命令`）、存储路径与迁移 / 导入 / 导出接线、无默认路径存储模型。
- 后端逻辑除导出落点外与 v1.13.1 一致。
- 提示：兜底导出位于安装目录，NSIS 更新会清空安装目录；需要长期保留的备份请用「导出实例（ZIP）」自选位置。
- 版本 1.13.2。覆盖安装，实例与设置保留。

**iOS**

- 暂无新版本，等待更新。
