# ADR-0003：各平台仓库保留对应前端源码

- 状态：已采纳
- 日期：2026-08-22

## 背景

平台版本可能各自携带不同的前端改动。单一源码位置要求每次差异都先合并回唯一仓库，跨仓库同步成本较高，也容易造成平台分支与源码位置脱节。

## 决定

主仓库维护未适配基线前端源码 `web/capacitor-ui/`；Android 与 Windows 仓库分别维护平台适配后的前端源码。各平台在自己仓库内构建并同步对应产物：

- Android 同步到 `app/src/main/assets/public/`
- Windows 同步到 `frontend-dist/` 并记录 `frontend.lock.json`
- 主仓库同步到 `docs/app/` 和 `docs/phone-demo.html`

三个仓库不再共享唯一源码位置；主仓库作为未适配基线，平台适配源码按平台差异独立维护，生成产物仍不接受手工功能修改。

## 结果

平台可以独立维护前端差异，同时保留各自完整构建链。跨平台接口变化仍通过 `TarvenEnv` 契约和 CI 校验控制。
